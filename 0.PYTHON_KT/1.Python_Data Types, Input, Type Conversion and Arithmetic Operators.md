## 1. Variables

A **variable** is a name used to store a value in a program.

The basic pattern is:

``` python
variable_name = value
```

Example:

``` python
name = "Annie"
balance = 3500.35
pin = 5652
vaccinated = True
```

Here:

-   `name` stores text.
-   `balance` stores a decimal number.
-   `pin` stores an integer.
-   `vaccinated` stores a Boolean value.

> In Python, you normally do not declare a variable's data type
> separately. Python determines the type from the assigned value.

------------------------------------------------------------------------

## 2. Basic Python Data Types

A **data type** describes what kind of value a variable contains and
therefore what operations can sensibly be performed on it.

### 2.1 `int` --- Integer

`int` represents whole numbers without a decimal point.

Examples:

``` python
age = 23
count = 7
temperature = -13
pin = 5652
```

Other valid integer values include:

``` text
23
7
-13
5637
563756273
```

### 2.2 `float` --- Decimal Number

`float` represents numbers containing a decimal/fractional component.

Examples:

``` python
pi = 3.142
price = 5.9
height = 73.5
balance = 3500.35
```

### 2.3 `str` --- String

`str` represents a sequence of characters.

Examples:

``` python
name = "Annie"
username = "amar"
code = "abc@123$"
ifsc = "HDFC123456"
```

Strings are enclosed in quotes.

``` python
message1 = "Hello"
message2 = 'Hello'
```

Both single and double quotes can create strings.

### 2.4 Characters in Python

The lecture uses `chr` to describe a single alphabet, digit, or symbol,
for example:

``` text
'A'
'$'
'@'
'5'
```

A useful Python-specific clarification is that Python does **not** have
a separate `char` primitive data type like Java or C. A single character
is simply a `str` whose length is 1.

``` python
gender = "F"
symbol = "@"
```

Both values are strings.

### 2.5 `bool` --- Boolean

A Boolean stores one of two logical values:

``` python
True
False
```

Example:

``` python
vaccinated = True
married = False
```

Python is case-sensitive, so write `True` and `False`, not `true` and
`false`.

Conceptually, these values contain a mixture of integers, floating-point

### Professional consideration

Just because a value contains digits does not always mean it should be
treated mathematically.

For example, identifiers such as telephone numbers, PINs, account
numbers and government identifiers are frequently represented as strings
in production systems because:

-   arithmetic is not performed on them;
-   leading zeros may be significant;
-   their format may contain letters or symbols;
-   the numeric value itself is not what the identifier represents.

For learning Python syntax, however, the lecture examples are
sufficient.

# 4. Reading User Input with `input()`

Python provides the built-in `input()` function to read information
entered by a user.

Example:

``` python
name = input("Enter your name: ")
print(name)
```

When Python reaches `input()`, execution pauses and waits for the user
to type something.

## Important rule: `input()` returns a string

Even when the user types:

``` text
12
```

Python initially receives it as:

``` python
"12"
```

This distinction is extremely important.

Consider:

``` python
a = input("Enter First Number : ")
b = input("Enter Second Number : ")

c = a + b

print(f"Sum = {c}")
```

If the user enters:

``` text
12
13
```

the output is:

``` text
Sum = 1213
```

Why?

Because Python is effectively evaluating:

``` python
"12" + "13"
```

For strings, `+` performs **concatenation** (joining), producing:

``` text
1213
```

It is not performing numeric addition.

# 5. Type Conversion

**Type conversion** means converting a value from one data type into
another.

Two important conversion functions introduced in this lesson are:

``` python
int()
float()
```

------------------------------------------------------------------------

## 5.1 Converting Input to `int`

One approach is to read the strings first and convert them when
performing the calculation.

``` python
a = input("Enter First Number : ")
b = input("Enter Second Number : ")

c = int(a) + int(b)

print(f"Sum = {c}")
```

Example input:

``` text
Enter First Number : 12
Enter Second Number : 13
```

Output:

``` text
Sum = 25
```

The conversions are:

``` text
"12" -> 12
"13" -> 13
```

so Python performs:

``` text
12 + 13 = 25
```

------------------------------------------------------------------------

## 5.2 Convert Immediately After `input()`

A cleaner and commonly used version converts the input as it is read:

``` python
a = int(input("Enter First Number : "))
b = int(input("Enter Second Number : "))

c = a + b

print(f"Sum = {c}")
```

Read this expression from the inside outward:

``` python
int(input("Enter First Number : "))
```

1.  `input(...)` reads the user's value as a string.
2.  `int(...)` converts that string to an integer.
3.  The integer is assigned to `a`.

For example:

``` text
User enters 12
      |
      v
input() returns "12"
      |
      v
int("12")
      |
      v
12
      |
      v
stored in a
```

------------------------------------------------------------------------

## 5.3 Reading Decimal Values with `float()`

If decimal input is required, use `float()`:

``` python
a = float(input("Enter First Number : "))
b = float(input("Enter Second Number : "))

c = a + b

print(f"Sum = {c}")
```

Example:

``` text
Enter First Number : 2.3
Enter Second Number : 3.4
Sum = 5.699999999999999
```

### Why isn't the result displayed exactly as `5.7`?

Most programming languages represent ordinary floating-point numbers
using binary floating-point arithmetic. Some decimal fractions cannot be
represented exactly in binary, so tiny precision artifacts can appear.

For normal display, formatting can be used:

``` python
print(f"Sum = {c:.1f}")
```

which produces:

``` text
Sum = 5.7
```

For domains such as financial calculations, Python's `decimal.Decimal`
may be more appropriate than binary floating-point arithmetic.

# 6. Python f-Strings

An **f-string** is a convenient way to insert variables or expressions
into text.

Example:

``` python
name = "Annie"
print(f"Hello {name}")
```

Output:

``` text
Hello Annie
```

The `f` before the opening quote enables expressions inside `{}`.

------------------------------------------------------------------------

## 6.1 Expressions Inside f-Strings

Suppose:

``` python
a = 10
b = 20
```

You can calculate directly inside the braces:

``` python
print(f"Sum = {a+b}")
print(f"Sum of {a} and {b} is {a+b}")
print(f"{a} + {b} = {a+b}")
```

Output:

``` text
Sum = 30
Sum of 10 and 20 is 30
10 + 20 = 30
```

This is useful because an f-string can contain both descriptive text and
evaluated Python expressions.

# 7. Arithmetic Operators

Python provides operators for common mathematical calculations.

  Operator   Meaning                  Example      Result
  ---------- ------------------------ ---------- --------
  `+`        Addition                 `5 + 2`         `7`
  `-`        Subtraction              `5 - 2`         `3`
  `*`        Multiplication           `5 * 2`        `10`
  `/`        Division                 `5 / 2`       `2.5`
  `//`       Floor division           `5 // 2`        `2`
  `%`        Modulo / remainder       `5 % 2`         `1`
  `**`       Exponentiation / power   `5 ** 2`       `25`

------------------------------------------------------------------------

## 7.1 Addition

``` python
result = 5 + 2
print(result)
```

Output:

``` text
7
```

------------------------------------------------------------------------

## 7.2 Subtraction

``` python
result = 5 - 2
print(result)
```

Output:

``` text
3
```

------------------------------------------------------------------------

## 7.3 Multiplication

``` python
result = 5 * 2
print(result)
```

Output:

``` text
10
```

------------------------------------------------------------------------

## 7.4 Division `/`

Normal division uses `/`.

``` python
result = 5 / 2
print(result)
```

Output:

``` text
2.5
```

In Python 3, `/` produces a floating-point result.

------------------------------------------------------------------------

## 7.5 Floor Division `//`

Floor division uses `//`.

``` python
result = 5 // 2
print(result)
```

Output:

``` text
2
```

For positive values such as `5 / 2`, the ordinary quotient is `2.5`,
while:

``` python
5 // 2
```

produces:

``` text
2
```

More precisely, `//` returns the mathematical **floor** of the quotient,
not simply "remove the decimal part." This distinction matters for
negative numbers.

For example:

``` python
print(-5 // 2)
```

Output:

``` text
-3
```

------------------------------------------------------------------------

## 7.6 Modulo `%`

Modulo gives the remainder after division.

``` python
result = 5 % 2
print(result)
```

Output:

``` text
1
```

Think of:

``` text
5 = (2 * 2) + 1
```

The remainder is `1`.

Modulo is frequently used to:

-   determine whether a number is even or odd;
-   perform cyclic calculations;
-   work with indexes and repeating patterns.

Example:

``` python
number = 10

print(number % 2)
```

Output:

``` text
0
```

Since the remainder is zero, `10` is divisible by `2`.

------------------------------------------------------------------------

## 7.7 Exponentiation `**`

Python uses `**` for powers.

``` python
print(2 ** 3)
print(3 ** 2)
print(5 ** 2)
print(5 ** 3)
```

Output:

``` text
8
9
25
125
```

Therefore:

``` text
2 ** 3 = 2 * 2 * 2 = 8
3 ** 2 = 3 * 3 = 9
5 ** 2 = 5 * 5 = 25
5 ** 3 = 5 * 5 * 5 = 125
```

Do not confuse:

``` python
5 * 3
```

with:

``` python
5 ** 3
```

The first means multiplication:

``` text
15
```

The second means exponentiation:

``` text
125
```

# 8. Complete Arithmetic Operator Program

The lecture demonstrates all of the arithmetic operators together.

``` python
a, b = 5, 2

print(f"{a} + {b} = {a+b}")
print(f"{a} - {b} = {a-b}")
print(f"{a} * {b} = {a*b}")
print(f"{a} / {b} = {a/b}")
print(f"{a} // {b} = {a//b}")
print(f"{a} % {b} = {a%b}")
print(f"{a} ** {b} = {a**b}")
```

Output:

``` text
5 + 2 = 7
5 - 2 = 3
5 * 2 = 10
5 / 2 = 2.5
5 // 2 = 2
5 % 2 = 1
5 ** 2 = 25
```

Notice this syntax:

``` python
a, b = 5, 2
```

It assigns multiple variables in one statement:

``` text
a = 5
b = 2
```

# 10. Practice Program --- Sum of the First N Natural Numbers

The sum of the first `n` natural numbers can be calculated using:

``` text
n(n + 1)
--------
   2
```

For example, if:

``` text
n = 5
```

then:

``` text
1 + 2 + 3 + 4 + 5 = 15
```

Using the formula:

``` text
5 * (5 + 1)
----------- = 15
     2
```

## Lecture Version

``` python
n = 5

sum = n * (n + 1) / 2

print(f"Sum of first {n} nums : {sum}")
```

Output:

``` text
Sum of first 5 nums : 15.0
```

Why `15.0` instead of `15`?

Because `/` performs normal division and returns a floating-point value.

## Integer-result version

For positive integer `n`, the result is always a whole number, so this
version can use integer division:

``` python
n = 5

total = n * (n + 1) // 2

print(f"Sum of first {n} nums : {total}")
```

Output:

``` text
Sum of first 5 nums : 15
```

`total` is used here instead of `sum` because Python already has a
built-in function named `sum()`.

# 11. Common Beginner Mistakes

## Mistake 1 --- Expecting `input()` to return a number

Incorrect for numeric addition:

``` python
a = input("Enter a: ")
b = input("Enter b: ")

print(a + b)
```

Input:

``` text
12
13
```

Output:

``` text
1213
```

Correct:

``` python
a = int(input("Enter a: "))
b = int(input("Enter b: "))

print(a + b)
```

Output:

``` text
25
```

------------------------------------------------------------------------

## Mistake 2 --- Using `int()` for decimal input

This works:

``` python
age = int(input("Enter age: "))
```

for input such as:

``` text
25
```

But this will fail if the user enters:

``` text
2.5
```

For decimal input, use:

``` python
value = float(input("Enter value: "))
```

------------------------------------------------------------------------

## Mistake 3 --- Confusing `/` and `//`

``` python
print(5 / 2)
```

Output:

``` text
2.5
```

while:

``` python
print(5 // 2)
```

Output:

``` text
2
```

They are different operators.

------------------------------------------------------------------------

## Mistake 4 --- Confusing `%` with percentage

In this context, `%` is the **modulo operator**.

``` python
5 % 2
```

means:

> What is the remainder when 5 is divided by 2?

Answer:

``` text
1
```

------------------------------------------------------------------------

## Mistake 5 --- Confusing `*` and `**`

``` python
5 * 3
```

means multiplication.

``` python
5 ** 3
```

means `5` raised to the power `3`.

# 14. Key Takeaways

1.  Variables store values.

``` python
age = 25
```

2.  Common beginner data types include:

``` text
int
float
str
bool
```

3.  A single character in Python is normally a one-character `str`.

4.  `input()` returns text (`str`), even when the user types digits.

5.  Convert numeric input when calculations are required:

``` python
int(input(...))
float(input(...))
```

6.  `/` and `//` are different:

``` text
5 / 2  -> 2.5
5 // 2 -> 2
```

7.  `%` returns a division remainder:

``` text
5 % 2 -> 1
```

8.  `**` performs exponentiation:

``` text
5 ** 2 -> 25
5 ** 3 -> 125
```

9.  f-strings make formatted output easy:

``` python
print(f"{a} + {b} = {a+b}")
```
