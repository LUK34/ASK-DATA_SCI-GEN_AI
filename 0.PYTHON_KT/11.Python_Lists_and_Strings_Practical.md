# Python Lists and Strings - Practical Beginner Notes

These notes are based on the lecture screenshots and continue the
earlier Python notes. They focus on practical list problems, searching

## 1. Working with List Positions

Consider:

``` python
nums = [3, 7, 4, 2, 9, 5, 8, 6]
```

Indexes are:

``` text
Value:  3  7  4  2  9  5  8  6
Index:  0  1  2  3  4  5  6  7
```

A very important distinction:

-   **Value** = the actual number stored in the list.
-   **Index** = the position where that value is stored.

For example:

``` python
print(nums[2])
```

Output:

``` text
4
```

Here `2` is the index and `4` is the value.

------------------------------------------------------------------------

## 2. Finding the First Even Number with Its Index

To find the **first even number**, scan from left to right and stop as
soon as an even value is found.

``` python
nums = [3, 7, 4, 2, 9, 5, 8, 6]

for i in range(len(nums)):
    if nums[i] % 2 == 0:
        print(f"First Even num : {nums[i]} @ Index : {i}")
        break
```

Output:

``` text
First Even num : 4 @ Index : 2
```

### Why `break`?

Without `break`, the loop would continue and print every even number.

`break` immediately terminates the loop after the first required match.

------------------------------------------------------------------------

## 3. Finding the Last Odd Number with Its Index

To find the last odd number efficiently, scan the list **backward**.

``` python
nums = [3, 7, 4, 2, 9, 5, 8, 6]

for i in range(len(nums) - 1, -1, -1):
    if nums[i] % 2 != 0:
        print(f"Last Odd num : {nums[i]} @ Index : {i}")
        break
```

Output:

``` text
Last Odd num : 5 @ Index : 5
```

The range:

``` python
range(len(nums) - 1, -1, -1)
```

means:

-   Start at the final valid index.
-   Continue backward.
-   Stop before `-1`.
-   Move by `-1` each time.

For an 8-element list, the indexes examined are:

``` text
7, 6, 5, 4, 3, 2, 1, 0
```

nums = [3, 7, 4, 2, 9, 5, 8, 6]

### 4.1 Sum of First and Last Elements

result = nums[0] + nums[-1]

### 4.2 Check Whether the First Element Is Even

``` python
if nums[0] % 2 == 0:
    print("First element is even")
else:
    print("First element is odd")
```

### 4.3 Average of All Elements

``` python
total = 0

for x in nums:
    total += x

average = total / len(nums)

print(f"Average : {average}")
```

You can also use:

``` python
average = sum(nums) / len(nums)
```

### 4.4 Check Whether Even or Odd Elements Are More Numerous

``` python
even_count = 0
odd_count = 0

for x in nums:
    if x % 2 == 0:
        even_count += 1
    else:
        odd_count += 1

if even_count > odd_count:
    print("More even numbers")
elif odd_count > even_count:
    print("More odd numbers")
else:
    print("Equal number of even and odd elements")
```

### 4.5 Check Whether the List Contains Zero

Beginner-friendly loop:

``` python
found = False

for x in nums:
    if x == 0:
        found = True
        break

if found:
    print("List contains zero")
else:
    print("List does not contain zero")
```

Python also provides:

``` python
if 0 in nums:
    print("List contains zero")
```

### 4.6 Check for Negative Numbers

``` python
for x in nums:
    if x < 0:
        print("Negative number found")
        break
else:
    print("No negative numbers")
```

The `else` attached to a `for` loop runs when the loop finishes without
encountering `break`.

### 4.7 Sum of Odd Numbers

``` python
odd_sum = 0

for x in nums:
    if x % 2 != 0:
        odd_sum += x

print(f"Odd numbers sum : {odd_sum}")
```

For the example list:

``` text
3 + 7 + 9 + 5 = 24
```

### 4.8 Average of Even Numbers

``` python
even_sum = 0
even_count = 0

for x in nums:
    if x % 2 == 0:
        even_sum += x
        even_count += 1

if even_count > 0:
    average = even_sum / even_count
    print(f"Even numbers average : {average}")
else:
    print("No even numbers")
```

The zero check is important because dividing by zero raises an error.

### 4.9 Swap First and Last Elements

``` python
nums[0], nums[-1] = nums[-1], nums[0]
print(nums)
```

### 4.10 Swap First Even and Last Odd Numbers

``` python
nums = [3, 7, 4, 2, 9, 5, 8, 6]

first_even_index = None
last_odd_index = None

for i in range(len(nums)):
    if nums[i] % 2 == 0:
        first_even_index = i
        break

for i in range(len(nums) - 1, -1, -1):
    if nums[i] % 2 != 0:
        last_odd_index = i
        break

if first_even_index is not None and last_odd_index is not None:
    nums[first_even_index], nums[last_odd_index] = (
        nums[last_odd_index],
        nums[first_even_index]
    )

print(nums)
```

Original:

``` text
[3, 7, 4, 2, 9, 5, 8, 6]
```

After swapping `4` and `5`:

``` text
[3, 7, 5, 2, 9, 4, 8, 6]
```

### 4.11 Swap Smallest and Largest Elements

``` python
nums = [3, 7, 4, 2, 9, 5, 8, 6]

small_index = 0
large_index = 0

for i in range(1, len(nums)):
    if nums[i] < nums[small_index]:
        small_index = i

    if nums[i] > nums[large_index]:
        large_index = i

nums[small_index], nums[large_index] = (
    nums[large_index],
    nums[small_index]
)

print(nums)
```

# 5. Introduction to Python Strings

A string is a sequence of characters.

``` python
s = "python"
```

The string contains:

``` text
p y t h o n
```

Just like lists, strings support:

-   `len()`
-   indexing
-   negative indexing
-   slicing
-   iteration

------------------------------------------------------------------------

## 6. String Length and Indexing

``` python
s = "python"

print(f"String : {s}")
print(f"Length : {len(s)}")

print(f"First char : {s[0]}")
print(f"Last char : {s[-1]}")
```

Output:

``` text
String : python
Length : 6
First char : p
Last char : n
```

> Note: One lecture screenshot appears to show `{-1}` in the
> last-character print statement. To access the actual last character,
> use `s[-1]`.

Indexes:

``` text
Character: p  y  t  h  o  n
Index:     0  1  2  3  4  5
Negative: -6 -5 -4 -3 -2 -1
```

# 7. Traversing a String

## Forward Using Indexes

``` python
s = "python"

for i in range(0, len(s), 1):
    print(s[i])
```

Output:

``` text
p
y
t
h
o
n
```

## Backward Using Indexes

``` python
for i in range(len(s) - 1, -1, -1):
    print(s[i])
```

Output:

``` text
n
o
h
t
y
p
```

## Direct Character Traversal

When the index is not required:

``` python
for ch in s:
    print(ch)
```

This is usually simpler and more Pythonic.

# 8. Reversing a String

Python slicing syntax is:

``` python
sequence[start:stop:step]
```

To reverse a string:

``` python
s = "AMAR"

print(f"Given String is : {s}")
print(f"Reverse String is : {s[::-1]}")
```

Output:

``` text
Given String is : AMAR
Reverse String is : RAMA
```

Why?

``` python
s[::-1]
```

uses a step of `-1`, so Python reads the sequence backward.

------------------------------------------------------------------------

# 9. Palindrome

A palindrome reads the same forward and backward.

Examples:

``` text
RACECAR
MADAM
LEVEL
```

A simple palindrome program:

``` python
s = "RACECAR"

if s == s[::-1]:
    print(f"{s} is Palindrome")
else:
    print(f"{s} is not Palindrome")
```

Output:

``` text
RACECAR is Palindrome
```

The key idea is:

``` python
s == s[::-1]
```

If the original and reversed strings are identical, the string is a
palindrome.

### Case-Insensitive Version

``` python
s = "RaceCar"
normalized = s.lower()

if normalized == normalized[::-1]:
    print("Palindrome")
else:
    print("Not palindrome")
```

# 10. Identifying Alphabet Characters Manually

Consider:

``` python
s = "abc@123$"
```

To print only alphabetic characters:

``` python
for ch in s:
    if ('A' <= ch <= 'Z') or ('a' <= ch <= 'z'):
        print(ch)
```

Output:

``` text
a
b
c
```

The longer equivalent condition is:

``` python
if (ch >= 'A' and ch <= 'Z') or (ch >= 'a' and ch <= 'z'):
```

Python also provides:

``` python
if ch.isalpha():
    print(ch)
```

The manual comparison is useful for understanding character ranges,
while `isalpha()` is normally clearer in application code.

------------------------------------------------------------------------

# 11. Counting Alphabets, Digits, and Symbols

For:

``` python
s = "abc@123$"
```

we want to classify every character.

``` python
s = "abc@123$"

c1 = c2 = c3 = 0

for ch in s:
    if ('A' <= ch <= 'Z') or ('a' <= ch <= 'z'):
        c1 += 1
    elif '0' <= ch <= '9':
        c2 += 1
    else:
        c3 += 1

print(f"Alphabets : {c1}")
print(f"Digits : {c2}")
print(f"Symbols : {c3}")
```

Output:

``` text
Alphabets : 3
Digits : 3
Symbols : 2
```

Character-by-character classification:

``` text
a -> alphabet
b -> alphabet
c -> alphabet
@ -> symbol
1 -> digit
2 -> digit
3 -> digit
$ -> symbol
```

Therefore:

``` text
Alphabets = 3
Digits    = 3
Symbols   = 2
```

### Built-in Alternative

``` python
for ch in s:
    if ch.isalpha():
        c1 += 1
    elif ch.isdigit():
        c2 += 1
    else:
        c3 += 1
```

# 13. Strings Are Immutable

This is an important Python concept.

**Immutable** means that once a string object is created, the contents
of that particular string object cannot be changed in place.

Consider:

``` python
s1 = "Hello"
s2 = "World"

print(f"S1 : {s1}")
print(f"S1 Loc : {id(s1)}")

print(f"S2 : {s2}")
print(f"S2 Loc : {id(s2)}")

s1 = s1 + s2

print(f"S1 : {s1}")
print(f"S1 Loc : {id(s1)}")

print(f"S2 : {s2}")
print(f"S2 Loc : {id(s2)}")
```

Conceptually:

``` text
Before:
s1 ----> "Hello"
s2 ----> "World"

After:
s1 ----> "HelloWorld"
s2 ----> "World"
```

The original `"Hello"` object was **not modified**. The expression:

``` python
s1 + s2
```

creates a resulting string, and `s1` is then rebound to that result.

This explains why the identity shown by:

``` python
id(s1)
```

can differ before and after concatenation.

> The exact numeric value returned by `id()` is implementation/runtime
> dependent. Do not expect the same numbers on another computer or
> another execution.

------------------------------------------------------------------------

# 14. Why You Cannot Modify a Character Directly

This fails:

``` python
s = "Hello"
s[0] = "Y"
```

Python raises:

``` text
TypeError: 'str' object does not support item assignment
```

because strings are immutable.

Instead, create another string:

``` python
s = "Hello"
s = "Y" + s[1:]

print(s)
```

Output:

``` text
Yello
```

# 15. Lists vs Strings

  -----------------------------------------------------------------------
  Feature                 List                    String
  ----------------------- ----------------------- -----------------------
  Ordered                 Yes                     Yes

  Indexed                 Yes                     Yes

  Negative indexing       Yes                     Yes

  Slicing                 Yes                     Yes

  Iterable                Yes                     Yes

  Can contain different   Yes                     No - a string is
  data types                                      character text

  Mutable                 Yes                     **No**
  -----------------------------------------------------------------------

Example of list mutation:

``` python
nums = [10, 20, 30]
nums[0] = 100

print(nums)
```

Output:

``` text
[100, 20, 30]
```

Equivalent string mutation is not permitted.

# 16. Important Operators Used in These Examples

### Modulus `%`

Returns the remainder:

``` python
8 % 2
```

Result:

``` text
0
```

Therefore:

``` python
x % 2 == 0
```

means `x` is even.

And:

``` python
x % 2 != 0
```

means `x` is odd.

### `+=`

``` python
count += 1
```

is shorthand for:

``` python
count = count + 1
```

### Membership `in`

``` python
0 in nums
```

checks whether a value occurs in a collection.

### Equality `==`

``` python
s == s[::-1]
```

compares values.

Do not confuse:

``` python
=
```

assignment

with:

``` python
==
```

comparison.

# 17. `break` in Search Problems

`break` is especially useful when searching for only one occurrence.

Example:

``` python
nums = [3, 7, 4, 2, 9, 5, 8, 6]

for i in range(len(nums)):
    if nums[i] % 2 == 0:
        print(nums[i])
        break
```

Execution:

``` text
3 -> odd, continue
7 -> odd, continue
4 -> even, print
break -> loop terminates
```

This avoids unnecessary iterations once the answer has been found.

# 18. Common Beginner Mistakes

### Mistake 1 - Confusing Index and Value

``` python
for i in range(len(nums)):
```

`i` is an index.

The corresponding value is:

``` python
nums[i]
```

But:

``` python
for x in nums:
```

`x` is already the value.

### Mistake 2 - Incorrect Last Character

Incorrect:

``` python
print(-1)
```

or:

``` python
print(f"{-1}")
```

Correct:

``` python
print(s[-1])
```

### Mistake 3 - Forgetting `break`

When searching for the **first** or **last** matching item, forgetting
`break` may cause additional matches to be processed.

### Mistake 4 - Off-by-One Errors

For:

``` python
len(nums) == 8
```

the final valid index is:

``` text
7
```

not `8`.

That is why reverse traversal starts with:

``` python
len(nums) - 1
```

### Mistake 5 - Division by Zero

When calculating the average of selected values:

``` python
average = total / count
```

always consider whether:

``` python
count == 0
```

is possible.

# 22. Key Takeaways

1.  Lists and strings are both ordered sequences and support indexing,
    slicing, and iteration.
2.  Index-based loops are useful when the **position** of an element is
    required.
3.  Direct iteration is simpler when only the **value** is needed.
4.  `break` is useful when searching for the first required match.
5.  Reverse traversal can be performed with
    `range(len(sequence)-1, -1, -1)`.
6.  `[::-1]` is a concise way to reverse lists and strings.
7.  A palindrome can be checked by comparing a string with its reverse.
8.  Characters can be classified using comparisons or methods such as
    `isalpha()` and `isdigit()`.
9.  Python strings are immutable: operations that appear to change a
    string create/rebind to another string object rather than modifying
    the original string object in place.
10. `id()` is useful for demonstrating object identity, but its numeric
    values should never be treated as fixed memory addresses that remain
    constant across executions.
