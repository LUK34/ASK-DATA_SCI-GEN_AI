# 1. Factors of a Number

A **factor** of a number is a number that divides it exactly, leaving a remainder of `0`.

For example, the factors of `6` are:

```text
1, 2, 3, 6
```

because:

```text
6 % 1 == 0
6 % 2 == 0
6 % 3 == 0
6 % 6 == 0
```

But:

```text
6 % 4 != 0
6 % 5 != 0
```

Therefore, `4` and `5` are not factors of `6`.

## Modulus Operator `%`

The modulus operator gives the remainder after division.

```python
print(6 % 2)   # 0
print(6 % 4)   # 2
```

So the basic condition for checking whether `i` is a factor of `n` is:

```python
if n % i == 0:
```

---

# 2. Print All Factors of a Number

To find all factors, test every integer from `1` through `n`.

```python
n = int(input("Enter n val : "))

for i in range(1, n + 1):
    if n % i == 0:
        print(f"{i} is factor")
```

Example:

```text
Enter n val : 6
1 is factor
2 is factor
3 is factor
6 is factor
```

## Why `range(1, n + 1)`?

Python excludes the ending value of `range()`.

For:

```python
range(1, 7)
```

Python produces:

```text
1, 2, 3, 4, 5, 6
```

Therefore, to test `n` itself, we use:

```python
range(1, n + 1)
```

# 3. Count the Factors

Instead of printing every factor, we can count how many factors exist.

Start with:

```python
count = 0
```

Every time a factor is found:

```python
count += 1
```

Complete program:

```python
n = int(input("Enter n val : "))

count = 0

for i in range(1, n + 1):
    if n % i == 0:
        count += 1

print(f"Count : {count}")
```

Example for `6`:

```text
Factors: 1, 2, 3, 6
Count: 4
```

---

# 4. Sum of Factors

We can also calculate the sum of all factors.

```python
n = int(input("Enter n val : "))

total = 0

for i in range(1, n + 1):
    if n % i == 0:
        total = total + i

print(f"Sum is : {total}")
```

For `10`:

```text
Factors = 1, 2, 5, 10
Sum = 18
```

The variable `total` is called an **accumulator** because it keeps accumulating values.

A shorter form is:

```python
total += i
```

# 5. Prime Numbers

A **prime number** has exactly two positive factors:

```text
1 and the number itself
```

Examples:

```text
2  -> 1, 2
3  -> 1, 3
5  -> 1, 5
7  -> 1, 7
11 -> 1, 11
```

A number such as `6` is not prime:

```text
Factors of 6 = 1, 2, 3, 6
```

It has four factors.

## Prime Number Program

```python
n = int(input("Enter n val : "))

count = 0

for i in range(1, n + 1):
    if n % i == 0:
        count += 1

if count == 2:
    print(f"{n} is Prime")
else:
    print(f"{n} is not Prime")
```

Example:

```text
Enter n val : 11
11 is Prime
```

Another example:

```text
Enter n val : 6
6 is not Prime
```

> Note: In production-quality code, it is also good practice to explicitly ensure `n > 1`, because prime numbers are defined only for integers greater than `1`.

For example:

```python
if n > 1 and count == 2:
    print(f"{n} is Prime")
else:
    print(f"{n} is not Prime")
```

# 6. Perfect Numbers

A **perfect number** is a positive integer whose proper factors add up to the number itself.

**Proper factors** are the factors excluding the number itself.

For `6`:

```text
Factors        = 1, 2, 3, 6
Proper factors = 1, 2, 3

1 + 2 + 3 = 6
```

Therefore:

```text
6 is a perfect number.
```

Another example is `28`:

```text
Proper factors = 1, 2, 4, 7, 14

1 + 2 + 4 + 7 + 14 = 28
```

So `28` is also perfect.

## Perfect Number Program

Notice that the loop stops before `n`:

```python
range(1, n)
```

This automatically excludes the number itself.

```python
n = int(input("Enter n val : "))

total = 0

for i in range(1, n):
    if n % i == 0:
        total = total + i

if total == n:
    print(f"{n} is Perfect")
else:
    print(f"{n} is not Perfect")
```

Example:

```text
Enter n val : 6
6 is Perfect
```

# 7. Introduction to Nested Loops

A **nested loop** means placing one loop inside another.

Example:

```python
for i in range(1, 6):

    for j in range(1, 6):
        print("Hi", end=" ")

    print()
```

Here:

- `i` controls the rows.
- `j` controls the columns.

Both ranges generate:

```text
1, 2, 3, 4, 5
```

The inner loop runs completely for every iteration of the outer loop.

Conceptually:

```text
i = 1 -> j = 1, 2, 3, 4, 5
i = 2 -> j = 1, 2, 3, 4, 5
i = 3 -> j = 1, 2, 3, 4, 5
i = 4 -> j = 1, 2, 3, 4, 5
i = 5 -> j = 1, 2, 3, 4, 5
```

Therefore, `"Hi"` is printed 25 times.

---

# 8. Understanding `end=" "`

Normally:

```python
print("Hi")
print("Hi")
```

produces:

```text
Hi
Hi
```

Every `print()` moves to the next line.

If we use:

```python
print("Hi", end=" ")
```

Python stays on the same line.

Example:

```python
for i in range(1, 6):
    print("Hi", end=" ")
```

Output:

```text
Hi Hi Hi Hi Hi
```

A separate:

```python
print()
```

moves the cursor to the next line.

This is extremely useful for pattern programs.

# 9. Print a Square of Stars

```python
for i in range(1, 6):

    for j in range(1, 6):
        print("*", end=" ")

    print()
```

Output:

```text
* * * * *
* * * * *
* * * * *
* * * * *
* * * * *
```

The outer loop creates the rows, while the inner loop creates the columns.

# 10. Thinking of Nested Loops as a Grid

For:

```python
for i in range(1, 10):
    for j in range(1, 10):
```

we can imagine a `9 x 9` coordinate grid.

```text
       j -> 1 2 3 4 5 6 7 8 9

i = 1
i = 2
i = 3
i = 4
i = 5
i = 6
i = 7
i = 8
i = 9
```

Each position has an `(i, j)` coordinate.

Examples:

```text
Top-left     = (1, 1)
Top-right    = (1, 9)
Center       = (5, 5)
Bottom-left  = (9, 1)
Bottom-right = (9, 9)
```

This coordinate idea makes pattern programs much easier to understand.

# 11. Print a Plus (`+`) Pattern

For a `9 x 9` grid, the center row and center column are both `5`.

Therefore, print `*` when:

```python
i == 5 or j == 5
```

Program:

```python
for i in range(1, 10):

    for j in range(1, 10):

        if i == 5 or j == 5:
            print("*", end=" ")
        else:
            print(" ", end=" ")

    print()
```

Approximate output:

```text
        *
        *
        *
        *
* * * * * * * * *
        *
        *
        *
        *
```

The condition:

```python
i == 5
```

creates the horizontal line.

The condition:

```python
j == 5
```

creates the vertical line.

`or` combines both.

# 12. Print a Hollow Square

For a `9 x 9` grid, the boundary consists of:

```text
Top row    -> i == 1
Bottom row -> i == 9
Left side  -> j == 1
Right side -> j == 9
```

Therefore:

```python
for i in range(1, 10):

    for j in range(1, 10):

        if i == 1 or j == 1 or i == 9 or j == 9:
            print("*", end=" ")
        else:
            print(" ", end=" ")

    print()
```

Output:

```text
* * * * * * * * *
*               *
*               *
*               *
*               *
*               *
*               *
*               *
* * * * * * * * *
```

This demonstrates how several conditions can be joined using `or`.

# 13. Print the Main Diagonal

The main diagonal contains positions where the row number equals the column number:

```text
(1,1)
(2,2)
(3,3)
(4,4)
...
(9,9)
```

Therefore, the condition is:

```python
i == j
```

Program:

```python
for i in range(1, 10):

    for j in range(1, 10):

        if i == j:
            print("*", end=" ")
        else:
            print(" ", end=" ")

    print()
```

Output:

```text
*
  *
    *
      *
        *
          *
            *
              *
                *
```

The key idea is:

```text
row == column
```

# 15. Print an `X` Pattern

An `X` is simply the combination of both diagonals.

Main diagonal:

```python
i == j
```

Opposite diagonal:

```python
i + j == 10
```

Therefore:

```python
for i in range(1, 10):

    for j in range(1, 10):

        if i == j or i + j == 10:
            print("*", end=" ")
        else:
            print(" ", end=" ")

    print()
```

Output:

```text
*               *
  *           *
    *       *
      *   *
        *
      *   *
    *       *
  *           *
*               *
```

# 16. Combining Multiple Pattern Conditions

More complicated patterns are still built from the same idea:

```python
if condition1 or condition2 or condition3:
    print("*", end=" ")
else:
    print(" ", end=" ")
```

The difficult-looking shape is therefore not one giant problem.

Break it into individual lines.

For example:

```text
Line 1 -> What values of i and j create it?
Line 2 -> What values of i and j create it?
Line 3 -> What values of i and j create it?
```

Then combine those conditions using `or`.

A pattern might use conditions such as:

```python
i == 5
j == 5
i == j
i + j == 10
i == 1
i == 9
j == 1
j == 9
```

The exact conditions depend on the required shape.

# 17. Using Ranges to Draw Only Part of a Line

Sometimes a condition such as:

```python
i == 5
```

draws an entire horizontal line, but we only want part of that line.

We can add another condition.

For example:

```python
i == 1 and j <= 5
```

means:

> Print only when we are on row `1` AND the column is between `1` and `5`.

Similarly:

```python
j == 5 and i <= 5
```

means:

> Print the vertical line at column `5`, but only in the upper half.

Another example:

```python
j == 1 and i >= 5
```

means:

> Print column `1`, starting from row `5` downward.

And:

```python
i == 9 and j >= 5
```

means:

> Print row `9`, starting from column `5`.

These conditions are useful for constructing custom shapes.

# 18. `and` vs `or` in Pattern Programs

Understanding these operators is essential.

## `and`

Both conditions must be true.

```python
if i == 1 and j <= 5:
```

This means:

```text
i must equal 1
AND
j must be 5 or less
```

## `or`

At least one condition must be true.

```python
if i == 5 or j == 5:
```

This means:

```text
Print if we are on row 5
OR
Print if we are on column 5
```

This creates a plus sign.

# 20. Why Is the Opposite Diagonal `i + j == 10`?

This can initially seem confusing.

Our grid uses:

```python
range(1, 10)
```

which produces:

```text
1, 2, 3, 4, 5, 6, 7, 8, 9
```

For the opposite diagonal:

```text
i=1 -> j=9
i=2 -> j=8
i=3 -> j=7
i=4 -> j=6
i=5 -> j=5
i=6 -> j=4
i=7 -> j=3
i=8 -> j=2
i=9 -> j=1
```

Every pair totals `10`.

Hence:

```python
i + j == 10
```

A useful generalization for a grid numbered from `1` to `n` is:

```python
i + j == n + 1
```

# 21. Factors, Prime Numbers, and Perfect Numbers — Relationship

These concepts all start from the same test:

```python
n % i == 0
```

That tells us:

```text
i is a factor of n
```

From there we can perform different operations.

### Print factors

```python
if n % i == 0:
    print(i)
```

### Count factors

```python
if n % i == 0:
    count += 1
```

### Sum factors

```python
if n % i == 0:
    total += i
```

### Prime check

```text
Number of factors == 2
```

### Perfect-number check

```text
Sum of proper factors == number
```

So these are not completely separate topics. They are different applications of the same factor-checking logic.

---

# 22. Complete Practice Program — Number Analysis

The concepts can be combined into one program.

```python
n = int(input("Enter a number : "))

count = 0
factor_sum = 0
proper_factor_sum = 0

print(f"Factors of {n}:")

for i in range(1, n + 1):

    if n % i == 0:
        print(i)

        count += 1
        factor_sum += i

        if i != n:
            proper_factor_sum += i

print(f"Factor count : {count}")
print(f"Factor sum   : {factor_sum}")

if n > 1 and count == 2:
    print(f"{n} is Prime")
else:
    print(f"{n} is not Prime")

if n > 0 and proper_factor_sum == n:
    print(f"{n} is Perfect")
else:
    print(f"{n} is not Perfect")
```

Example:

```text
Enter a number : 6

Factors of 6:
1
2
3
6

Factor count : 4
Factor sum   : 12
6 is not Prime
6 is Perfect
```

# Key Takeaway

The most important idea from this lesson is to learn to convert a problem into a **condition**.

For number problems:

```python
n % i == 0
```

is the foundation for factors, prime numbers, and perfect numbers.

For pattern problems, think of the screen as a coordinate grid:

```text
(i, j) = (row, column)
```

Then ask:

> At which `(i, j)` positions should a star be printed?

Once those positions are expressed as conditions such as:

```python
i == j
i + j == 10
i == 5
j == 5
```

the pattern becomes much easier to program.
