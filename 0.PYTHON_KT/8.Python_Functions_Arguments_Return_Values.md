The examples are reconstructed from the lecture screenshots and

## 1. Multiplication Table Using a Function

Instead of writing nested-loop logic every time, we can move the
multiplication-table logic into a reusable function.

``` python
def table(n):
    for i in range(1, 11):
        print(f"{n} * {i} = {n*i}")
    return

for n in range(5, 11):
    table(n)
```

### How it works

`table(n)` accepts one number. The inner `for` loop multiplies that
number by every integer from `1` through `10`.

The outer loop calls the function for `5, 6, 7, 8, 9, 10`.

For example:

``` text
5 * 1 = 5
5 * 2 = 10
...
10 * 9 = 90
10 * 10 = 100
```

### Important `range()` reminder

``` python
range(5, 11)
```

generates:

``` text
5, 6, 7, 8, 9, 10
```

The ending value (`11`) is excluded.

## 2. Functions Can Accept Different Numbers of Arguments

A function can receive one argument or many arguments depending on the
task.

### One argument

``` python
def is_alphabet(ch):
    # logic
    return
```

Possible calls:

``` python
is_alphabet('R')
is_alphabet('$')
```

### Another one-argument function

``` python
def is_prime(num):
    # logic
    return
```

Possible calls:

``` python
is_prime(7)
is_prime(10)
```

### Multiple arguments

``` python
def details(num, name, salary, location):
    # print/process details
    return
```

A corresponding call would supply four values:

``` python
details(101, "John", 50000, "Kuwait")
```

### Vowel example

``` python
def is_vowel(ch):
    # logic
    return
```

Possible calls:

``` python
is_vowel('r')
is_vowel('i')
```

The number of supplied arguments should match the parameters expected by
the function unless optional/default or variable-length parameters are
being used.

# 3. Classification of Functions

For this introductory lesson, functions can be classified using two
questions:

1.  **Does the function receive arguments?**
2.  **Does the function return a value?**

This produces four common combinations:

  Type   Arguments   Returned value
  ------ ----------- ----------------
  1      No          No
  2      Yes         No
  3      No          Yes
  4      Yes         Yes

These categories are useful for learning how information enters and
leaves a function.

------------------------------------------------------------------------

## 4. No Arguments and No Return Value

``` python
def clear():
    print("clear all")
    return

clear()
```

Here:

-   `clear()` receives no arguments.
-   The function performs an action by printing.
-   `return` has no value after it.

Output:

``` text
clear all
```

### Is `return` required here?

No. Python automatically reaches the end of the function and returns
`None`.

Therefore this also works:

``` python
def clear():
    print("clear all")
```

An explicit empty `return` can still be used when you want to end
execution of the function at that point.

# 5. With Arguments and No Useful Return Value

The lecture uses addition as an example:

``` python
def add(a, b):
    c = a + b
    print(f"Sum = {c}")
    return

add(10, 20)
```

Output:

``` text
Sum = 30
```

### Parameters and arguments

In:

``` python
def add(a, b):
```

`a` and `b` are **parameters**.

In:

``` python
add(10, 20)
```

`10` and `20` are **arguments**.

During the call:

``` text
a = 10
b = 20
```

Then:

``` python
c = a + b
```

produces:

``` text
c = 30
```

The function itself prints the result.

------------------------------------------------------------------------

# 6. With Arguments and With a Return Value

A more reusable design is to return the calculated value:

``` python
def add(a, b):
    c = a + b
    return c

res = add(10, 20)
print(f"Sum = {res}")
```

Output:

``` text
Sum = 30
```

The important difference is that the calculation and presentation are
now separated.

``` python
return c
```

sends `30` back to the caller.

Then:

``` python
res = add(10, 20)
```

stores the returned value in `res`.

Conceptually:

``` text
10, 20
   ↓
add(a, b)
   ↓
c = 30
   ↓
return 30
   ↓
res = 30
```

This is usually more reusable because the caller can decide what to do
with the result.

For example:

``` python
result = add(10, 20)

print(result)
print(result * 2)
```

# 7. No Arguments and With a Return Value

The lecture demonstrates this category using π:

``` python
def getPI():
    return 3.142

pi = getPI()
print(f"PI val : {pi}")
```

Output:

``` text
PI val : 3.142
```

The function receives nothing:

``` python
getPI()
```

but sends a value back:

``` python
return 3.142
```

A professional note: for real calculations, Python provides a more
accurate value through `math.pi`.

``` python
import math

print(math.pi)
```

# 8. Complete Four-Category View

The lecture's classification can therefore be summarized as:

``` text
                    RETURN VALUE
                  No             Yes
             +-------------+-------------+
Arguments No | Type 1      | Type 3      |
             | clear()     | getPI()     |
             +-------------+-------------+
Arguments Yes| Type 2      | Type 4      |
             | add(a, b)   | add(a, b)   |
             +-------------+-------------+
```

The distinction is about **data flow**:

``` text
Arguments → Function → Return Value
```

Arguments send information **into** a function. A return value sends
information **back out** to the caller.

# 9. Returning Messages from a Function --- Even/Odd

Instead of printing inside the function, we can return a message.

``` python
def is_even(n):
    if n % 2 == 0:
        return f"{n} is even"
    else:
        return f"{n} is not even"

msg = is_even(13)
print(msg)
```

Output:

``` text
13 is not even
```

If we call:

``` python
msg = is_even(22)
print(msg)
```

the output is:

``` text
22 is even
```

### Why `% 2`?

The modulus operator `%` gives the remainder after division.

``` python
22 % 2
```

returns `0`, so `22` is even.

``` python
13 % 2
```

returns `1`, so `13` is odd.

### Professional alternative

A function named `is_even` often returns a Boolean:

``` python
def is_even(n):
    return n % 2 == 0

print(is_even(22))
print(is_even(13))
```

Output:

``` text
True
False
```

This makes the function easier to reuse in conditions:

``` python
if is_even(22):
    print("Even number")
```

# 10. Factorial Using a Function

The lecture calculates factorial using a loop:

``` python
def factorial(n):
    fact = 1

    for i in range(1, n + 1):
        fact = fact * i

    return fact

res = factorial(5)
print(f"Factorial : {res}")
```

Output:

``` text
Factorial : 120
```

## What is factorial?

For a positive integer `n`:

``` text
n! = n × (n-1) × (n-2) × ... × 1
```

Therefore:

``` text
5! = 5 × 4 × 3 × 2 × 1
   = 120
```

### Step-by-step execution

Initially:

``` text
fact = 1
```

For `factorial(5)`, the loop processes `1` through `5`:

    `i` Calculation     `fact`
  ----- ------------- --------
      1 `1 * 1`              1
      2 `1 * 2`              2
      3 `2 * 3`              6
      4 `6 * 4`             24
      5 `24 * 5`           120

Finally:

``` python
return fact
```

returns `120`.

### Why start with `fact = 1`?

Because `1` is the multiplicative identity. Starting with `0` would make
every multiplication produce `0`.

# 11. Checking Whether a Character Is an Alphabet

The lecture also shows a function that checks whether a character lies
within the English uppercase or lowercase alphabet ranges.

``` python
def is_alphabet(ch):
    if (ch >= 'A' and ch <= 'Z') or (ch >= 'a' and ch <= 'z'):
        return f"{ch} is alphabet"
    else:
        return f"{ch} is not alphabet"

msg = is_alphabet('H')
print(msg)
```

Output:

``` text
H is alphabet
```

The condition checks either:

``` text
'A' <= ch <= 'Z'
```

or:

``` text
'a' <= ch <= 'z'
```

Python also supports chained comparisons, so the condition can be
written more readably:

``` python
def is_alphabet(ch):
    if ('A' <= ch <= 'Z') or ('a' <= ch <= 'z'):
        return f"{ch} is alphabet"
    return f"{ch} is not alphabet"
```

Python additionally provides:

``` python
ch.isalpha()
```

but note that `isalpha()` recognizes alphabetic characters beyond only
English `A-Z`/`a-z`.

# 12. `print()` vs `return`

This distinction is extremely important.

Consider:

``` python
def add(a, b):
    print(a + b)
```

Calling:

``` python
result = add(10, 20)
```

prints `30`, but the function did not return `30`.

`result` therefore receives:

``` python
None
```

Compare that with:

``` python
def add(a, b):
    return a + b

result = add(10, 20)
```

Now:

``` text
result = 30
```

A simple way to remember it:

``` text
print()  → displays something
return   → sends a value back
```

Returning a value does **not** automatically display it.

For example:

``` python
def add(a, b):
    return a + b

add(10, 20)
```

In a normal Python script, this produces no visible output.

You need something such as:

``` python
print(add(10, 20))
```

# 13. `return` Ends Function Execution

When Python executes `return`, the current function stops.

``` python
def demo():
    print("Before return")
    return
    print("After return")

demo()
```

Output:

``` text
Before return
```

The second `print()` is never executed.

Likewise:

``` python
def square(n):
    return n * n
    print("Finished")
```

`print("Finished")` is unreachable.

# 14. Function Definition vs Function Call

A function definition tells Python what the function should do:

``` python
def factorial(n):
    fact = 1
    for i in range(1, n + 1):
        fact *= i
    return fact
```

Nothing is calculated merely because the function was defined.

Execution happens when it is called:

``` python
factorial(5)
```

To retain the returned value:

``` python
result = factorial(5)
```

To display it:

``` python
print(result)
```

# 15. Combining Functions with Loops

The multiplication-table example demonstrates an important programming
principle: functions and loops can work together.

``` python
def table(n):
    for i in range(1, 11):
        print(f"{n} * {i} = {n * i}")

for n in range(5, 11):
    table(n)
```

The responsibilities are separated:

``` text
Outer loop
    ↓
chooses each table number
    ↓
table(n)
    ↓
inner loop prints 1–10 multiples
```

This is cleaner than repeating the multiplication logic for every
number.

# 17. Common Beginner Mistakes

### Forgetting parentheses when calling

Incorrect:

``` python
factorial
```

Correct:

``` python
factorial(5)
```

### Confusing parameters with arguments

``` python
def add(a, b):
```

`a` and `b` are parameters.

``` python
add(10, 20)
```

`10` and `20` are arguments.

### Expecting `print()` to return the displayed value

``` python
def add(a, b):
    print(a + b)

x = add(10, 20)
print(x)
```

Output:

``` text
30
None
```

### Forgetting to use a returned value

``` python
def add(a, b):
    return a + b

add(10, 20)
```

The result is calculated but not displayed or stored.

Better:

``` python
result = add(10, 20)
print(result)
```

### Incorrect indentation

Python uses indentation to define blocks.

Correct:

``` python
def factorial(n):
    fact = 1
    for i in range(1, n + 1):
        fact *= i
    return fact
```

# 20. Quick Revision Cheat Sheet

``` python
# Function definition
def function_name():
    pass


# Function with arguments
def add(a, b):
    print(a + b)


# Function with return value
def add(a, b):
    return a + b


# Store returned result
result = add(10, 20)


# Print returned result
print(result)


# Directly print returned result
print(add(10, 20))
```

Remember the central idea:

``` text
arguments → function → return value
```

and:

``` text
print() displays a value
return sends a value back
```

## Final Takeaway

Functions allow us to divide a program into small, reusable units. A
function is defined using `def`, can receive information through
parameters, can perform calculations or actions, and can optionally send
a result back with `return`.

At this stage, the most important concepts to be comfortable with are:

-   defining and calling functions;
-   parameters versus arguments;
-   functions with and without arguments;
-   functions with and without return values;
-   the difference between `print()` and `return`;
-   using conditions and loops inside functions;
-   storing and reusing returned results.

These ideas become especially important later in Python, object-oriented
programming, data processing, APIs, machine learning, and Generative AI
applications.
