# Python Functions and Lambda Expressions

This section continues the Python beginner notes and explains **functions with arguments**, **return values**, and **lambda expressions**.

---

## 1. What is a Function?

A **function** is a reusable block of code designed to perform a particular task.

Instead of writing the same logic repeatedly, we can define it once and call it whenever needed.

Basic syntax:

```python
def function_name():
    # code
```

Example:

```python
def hello():
    print("Hello all")

hello()
```

Output:

```text
Hello all
```

---

## 2. Function Arguments

An **argument** is a value supplied to a function when the function is called.

For example:

```python
def add(a, b):
    print(f"Sum = {a + b}")

add(10, 20)
```

Here:

- `add` is the function name.
- `a` and `b` are parameters.
- `10` and `20` are arguments passed when calling the function.
- `a + b` calculates the sum.

Output:

```text
Sum = 30
```

---

## 3. Function with Arguments and No Return Value

The screenshot demonstrates a function that accepts arguments but does not return the calculated result to the caller.

```python
# With args & no return values

def add(a, b):
    print(f"Sum = {a + b}")
    return

add(10, 20)
```

Output:

```text
Sum = 30
```

### What happens here?

When this is executed:

```python
add(10, 20)
```

Python assigns:

```text
a = 10
b = 20
```

Then:

```python
a + b
```

becomes:

```text
10 + 20 = 30
```

The function itself prints the result.

### About `return`

This code contains:

```python
return
```

A `return` without a value immediately exits the function and effectively returns `None`.

In this particular example, because `return` is already at the end of the function, it is optional:

```python
def add(a, b):
    print(f"Sum = {a + b}")
```

---

# 4. Lambda Expression with Arguments and No Returned Result

The same basic behavior can be written using a lambda expression:

```python
add = lambda a, b: print(f"Sum = {a + b}")

add(30, 50)
```

Output:

```text
Sum = 80
```

A lambda expression creates a small anonymous function.

The general syntax is:

```python
lambda parameters: expression
```

In this example:

```python
lambda a, b: print(f"Sum = {a + b}")
```

accepts two arguments and executes the `print()` expression.

> Note: technically `print()` returns `None`, so this lambda itself evaluates to `None` after printing the result.

---

# 5. Normal Function vs Lambda

The following normal function:

```python
def add(a, b):
    print(f"Sum = {a + b}")
```

can be represented compactly as:

```python
add = lambda a, b: print(f"Sum = {a + b}")
```

Both can be called using:

```python
add(10, 20)
```

However, normal functions are generally preferable when the logic contains multiple statements or needs clear documentation. Lambda expressions are most useful for short, simple expressions.

---

# 6. Function with Arguments and Return Value

A function can calculate a result and send that value back to the caller using `return`.

```python
# With args & with return values

def add(a, b):
    return a + b

res = add(10, 20)

print(f"Sum = {res}")
```

Output:

```text
Sum = 30
```

The important line is:

```python
return a + b
```

The function calculates:

```text
10 + 20
```

and returns:

```text
30
```

The returned value is then stored in:

```python
res
```

Conceptually:

```text
add(10, 20)
      |
      v
  10 + 20
      |
      v
     30
      |
      v
res = 30
```

Then:

```python
print(f"Sum = {res}")
```

prints:

```text
Sum = 30
```

---

# 7. Lambda Expression with Arguments and Return Value

The same addition operation can be written using lambda:

```python
add = lambda a, b: a + b

res = add(30, 50)

print(f"Sum = {res}")
```

Output:

```text
Sum = 80
```

The expression:

```python
lambda a, b: a + b
```

automatically returns the result of:

```python
a + b
```

Unlike a normal `def` function, we do not write:

```python
return a + b
```

inside a lambda.

---

# 8. `print()` vs `return`

This distinction is extremely important.

Consider:

```python
def add(a, b):
    print(a + b)
```

This **displays** the result but does not return that numeric result.

Compare it with:

```python
def add(a, b):
    return a + b
```

This sends the calculated value back to the caller.

For example:

```python
def add(a, b):
    return a + b

result = add(10, 20)

print(result)
```

Output:

```text
30
```

Because `result` contains the returned value, it can also be reused:

```python
final_result = result * 2

print(final_result)
```

Output:

```text
60
```

# 9. Four Common Function Patterns

Functions are often introduced using four combinations:

| Type | Arguments? | Return value? | Example |
|---|---|---|---|
| No arguments, no return value | No | No | `hello()` |
| Arguments, no return value | Yes | No | `add(10, 20)` prints internally |
| No arguments, return value | No | Yes | `get_value()` |
| Arguments and return value | Yes | Yes | `add(10, 20)` returns `30` |

Example of the fourth pattern:

```python
def add(a, b):
    return a + b

result = add(10, 20)
print(result)
```

# 10. Normal Function and Lambda Comparison

Normal function:

```python
def add(a, b):
    return a + b
```

Equivalent lambda for this simple expression:

```python
add = lambda a, b: a + b
```

Usage:

```python
print(add(10, 20))
```

Output:

```text
30
```

### When should you use each?

Use a **normal function** when:

- the function contains multiple statements;
- the logic is complex;
- readability is important;
- documentation or type hints are useful;
- the function will be reused extensively.

Use a **lambda** when:

- the operation is very short;
- only a single expression is needed;
- a function is needed temporarily, such as with `sorted()`, `map()`, or `filter()`.

---

# 11. Important Lambda Limitation

A lambda contains a **single expression**.

Valid:

```python
square = lambda x: x * x
```

Valid:

```python
add = lambda a, b: a + b
```

For larger logic, prefer a normal function:

```python
def calculate(a, b):
    total = a + b
    doubled = total * 2
    return doubled
```

This is clearer than trying to force complex logic into a lambda.

# 12. Additional Lambda Examples

### Square a number

```python
square = lambda x: x ** 2

print(square(5))
```

Output:

```text
25
```

### Multiply two numbers

```python
multiply = lambda a, b: a * b

print(multiply(5, 4))
```

Output:

```text
20
```

### Check whether a number is even

```python
is_even = lambda number: number % 2 == 0

print(is_even(10))
print(is_even(7))
```

Output:

```text
True
False
```

# 13. Key Takeaways

- Functions make code reusable and easier to maintain.
- Parameters are variables declared in a function definition.
- Arguments are actual values supplied when calling the function.
- `print()` displays information.
- `return` sends a value back to the caller.
- A returned value can be stored in a variable and reused.
- `return` without a value returns `None`.
- Lambda expressions create small anonymous functions.
- Lambda syntax is `lambda parameters: expression`.
- A lambda automatically returns the result of its expression.
- For complex logic, prefer a normal `def` function.
