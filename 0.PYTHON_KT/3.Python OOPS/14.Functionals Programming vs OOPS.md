## 1. What is list comprehension?

A **list comprehension** is a compact way to construct a new Python list by iterating over an iterable, optionally filtering elements, and optionally transforming them.

```python
numbers = [1, 2, 3, 4, 5]
doubled = [x * 2 for x in numbers]
print(doubled)
```

**Output**

```text
[2, 4, 6, 8, 10]
```

The expression `x * 2` is evaluated for each number `x` in `numbers`. A new list is produced; the original list is unchanged.

## 2. Traditional loops versus comprehension

### Traditional approach (from the lecture)

```python
# Normal way
nums = [1, 2, 3, 4, 5]
result = []
for x in nums:
    result.append(x * 2)
print(result)
```

**Output:** `[2, 4, 6, 8, 10]`

### Equivalent list comprehension

```python
nums = [1, 2, 3, 4, 5]
result = [x * 2 for x in nums]
print(result)
```

**Output:** `[2, 4, 6, 8, 10]`

Both versions generate the same values. The comprehension is shorter; a normal loop is often easier to extend when the logic becomes complicated.

## 3. Syntax and execution order

### Transform every item

```python
[expression for variable in iterable]
```

### Filter items

```python
[expression for variable in iterable if condition]
```

### Choose between two results

```python
[value_if_true if condition else value_if_false for variable in iterable]
```

**Mental model:**

```text
Input iterable → take an item → optional filter → evaluate expression → append to new list
```

Notice the difference between the `if` at the **end** (filtering) and `if ... else` **before** `for` (choosing what to output). The `if ... else` form keeps one result for each input item.

## 4. Number-based examples

### 4.1 Double every number

```python
# Find doubles
nums = [1, 2, 3, 4, 5]
result = [x * 2 for x in nums]
print(result)
```

**Output:** `[2, 4, 6, 8, 10]`

### 4.2 Find even numbers

```python
# Find even numbers
nums = [1, 2, 3, 4, 5, 6, 7, 8, 9]
result = [x for x in nums if x % 2 == 0]
print(result)
```

**Output:** `[2, 4, 6, 8]`

The `%` operator computes the remainder. A number is even when dividing it by 2 leaves remainder `0`.

### 4.3 Add five to every number

```python
# Add 5 to each number
nums = [1, 2, 3, 4, 5]
result = [x + 5 for x in nums]
print(result)
```

**Output:** `[6, 7, 8, 9, 10]`

### 4.4 Square only even numbers

```python
# Find squares of even numbers
nums = [1, 2, 3, 4, 5, 6, 7, 8, 9]
result = [x ** 2 for x in nums if x % 2 == 0]
print(result)
```

**Output:** `[4, 16, 36, 64]`

The filter selects `2, 4, 6, 8`, and `** 2` squares each selected number.

## 5. Conditional expressions: even or odd

Instead of removing odd numbers, we can label **every** number.

```python
# Print number and its type
nums = [1, 2, 3, 4, 5]
result = [(x, "Even") if x % 2 == 0 else (x, "Odd") for x in nums]
print(result)
```

**Output:**

```text
[(1, 'Odd'), (2, 'Even'), (3, 'Odd'), (4, 'Even'), (5, 'Odd')]
```

Each result is a **tuple** containing the number and its label. This is not Python's `type()` classification: `Even` and `Odd` describe the number's parity.

Compare:

```python
# Filtering: removes odd numbers
[x for x in nums if x % 2 == 0]
# [2, 4]

# Conditional expression: labels all numbers
[(x, "Even") if x % 2 == 0 else (x, "Odd") for x in nums]
# [(1, 'Odd'), (2, 'Even'), (3, 'Odd'), (4, 'Even'), (5, 'Odd')]
```

## 6. String-based examples

The lecture uses:

```python
words = ["python", "java", "react", "sql", "flask"]
```

### 6.1 Copy the elements into a new list

```python
res = [x for x in words]
print(res)
```

**Output:**

```text
['python', 'java', 'react', 'sql', 'flask']
```

For a simple shallow list copy, `words.copy()` is also idiomatic.

### 6.2 Convert words to uppercase

```python
res = [x.upper() for x in words]
print(res)
```

**Output:**

```text
['PYTHON', 'JAVA', 'REACT', 'SQL', 'FLASK']
```

`.upper()` creates an uppercase string; it does not change the original strings.

### 6.3 Find each word's length

```python
res = [len(x) for x in words]
print(res)
```

**Output:** `[6, 4, 5, 3, 5]`

`len()` counts the number of characters in each string.

### 6.4 Create `(word, length)` tuples

```python
res = [(x, len(x)) for x in words]
print(res)
```

**Output:**

```text
[('python', 6), ('java', 4), ('react', 5), ('sql', 3), ('flask', 5)]
```

This combines a word with a calculated property. It can be useful for preparing text-processing data.

### 6.5 Filter words longer than five characters

```python
res = [x for x in words if len(x) > 5]
print(res)
```

**Output:** `['python']`

The condition is strictly greater than 5. Words with exactly 5 characters are excluded.

### 6.6 Extract the first character

```python
res = [x[0] for x in words]
print(res)
```

**Output:** `['p', 'j', 'r', 's', 'f']`

Python uses zero-based indexing: index `0` is the first character.

### 6.7 Extract the last character

```python
res = [x[-1] for x in words]
print(res)
```

**Output:** `['n', 'a', 't', 'l', 'k']`

Index `-1` refers to the last character. **Caution:** `x[0]` and `x[-1]` raise `IndexError` for an empty string. You can filter empty strings first if your data may contain them.

## 8. Introduction to programming paradigms

The final two screenshots compare code written using **standalone variables and functions** with code organized inside a **class**.

### Important terminology clarification

The lecturer labels the left side *Functional Programming*. Strictly speaking, merely using standalone functions does **not** make a program functional. The left example is better described as a **simple procedural / function-based program**.

- **Procedural programming:** organizes instructions into procedures or functions, often with state that changes.
- **Functional programming:** emphasizes composing functions, often pure functions and immutable data, and minimizing side effects.
- **Object-oriented programming (OOP):** organizes data and behavior around classes and objects.

Python supports all three approaches, and they can coexist in the same project.

| Aspect | Function-based / procedural example | Object-oriented example |
|---|---|---|
| Main organization | Variables and functions | Classes and objects |
| Data and behavior | Can be separate | Can be grouped together |
| Calling code | `fun()` | `Test.fun()` or `obj.fun()` |
| State | Local/global variables | Class or instance attributes |
| Useful for | Small scripts, simple transformations | Modeling entities with related behavior |
| Security | Depends on implementation | Also depends on implementation |

**Important:** OOP does not automatically provide cybersecurity, and functional code is not inherently disconnected from the internet. A calculator, traffic-signal controller, or banking application can be built using multiple programming styles. Network access and protection of sensitive information depend on architecture, authorization, encryption, deployment, and other controls—not simply on whether classes are used.

## 9. Standalone functions versus classes

### 9.1 Function-based example from the lecture

```python
a = 10

def fun():
    print("fun...")
    return

print(a)
fun()
```

**Output:**

```text
10
fun...
```

`a` is a module-level variable; `fun()` is a module-level function. Both can be accessed by name in the same module.

### 9.2 Class-based example from the lecture

```python
class Test:
    a = 10

    def fun():
        print("fun...")
        return

print(Test.a)
Test.fun()
```

**Output:**

```text
10
fun...
```

This example is valid because `Test.fun()` is called **on the class**, and `fun()` takes no parameters. Here `a` is a **class attribute**.

However, this is **not** the usual pattern for an instance method. If you write `obj = Test()` and call `obj.fun()`, Python tries to supply the instance as the first argument, producing a `TypeError` because the lecture's method does not accept `self`.

### 9.3 Preferred class design with an instance

```python
class Test:
    def __init__(self, a):
        self.a = a

    def fun(self):
        print("fun...")

obj = Test(10)
print(obj.a)
obj.fun()
```

**Output:**

```text
10
fun...
```

Explanation:

1. `class Test:` declares a class (a blueprint for objects).
2. `__init__` initializes each new instance.
3. `self.a` stores an attribute on that instance.
4. `self` refers to the instance receiving the method call.
5. `obj = Test(10)` creates an object.
6. `obj.fun()` invokes the instance method.

### 9.4 When a method does not need an instance

Use `@staticmethod` to make the lecture's class-call intention explicit:

```python
class Test:
    a = 10

    @staticmethod
    def fun():
        print("fun...")

print(Test.a)
Test.fun()
```

This allows the function to be called through the class without requiring `self`.

## 10. Encapsulation and sensitive information

**Encapsulation** means grouping data and the operations that use it into a coherent interface. It can help prevent accidental misuse and make code easier to maintain.

The screenshots refer to a banking application and protecting members. A realistic introductory example:

```python
class BankAccount:
    def __init__(self, owner, balance=0):
        self.owner = owner
        self._balance = balance

    def deposit(self, amount):
        if amount <= 0:
            raise ValueError("Deposit must be positive")
        self._balance += amount

    def get_balance(self):
        return self._balance

account = BankAccount("Amar", 100)
account.deposit(50)
print(account.get_balance())
```

**Output:** `150`

The leading underscore in `_balance` is a **convention** meaning “internal use”; it does not enforce private access. Python's double-underscore name mangling also is not a security boundary. A real banking system requires server-side authorization, secure storage, audit logs, and other controls.

## 11. Best practices and common mistakes

- Use list comprehensions for **readable transformations and filters**; use normal loops for complex workflows or side effects.
- Prefer descriptive names such as `numbers`, `even_numbers`, and `word_lengths` in production code.
- Remember that `x % 2 == 0` checks parity, while `x ** 2` squares a number.
- Do not confuse `[x for x in items if condition]` (filter) with `[a if condition else b for x in items]` (choose output).
- Avoid `x[0]` or `x[-1]` if `x` could be empty.
- Use `self` for normal instance methods; `@staticmethod` for functions intentionally placed in a class that do not need instance or class state.
- Do not assume a class automatically makes attributes private or an application secure.
- Prefer clear, testable code over compressing everything into one line.
