# 1. Factors of a Number

A **factor** is a number that divides another number exactly, leaving no
remainder.

For example:

``` text
n = 6
```

Possible values from `1` to `6` are:

``` text
1, 2, 3, 4, 5, 6
```

We can check each value using the modulus operator `%`:

``` text
6 % 1 == 0
6 % 2 == 0
6 % 3 == 0
6 % 4 != 0
6 % 5 != 0
6 % 6 == 0
```

Therefore, the factors of `6` are:

``` text
1, 2, 3, 6
```

The main condition used to identify a factor is:

``` python
n % i == 0
```

If the remainder is zero, `i` is a factor of `n`.

------------------------------------------------------------------------

# 2. Print All Factors

The lecture first demonstrates how to print every factor of a number.

``` python
n = int(input("Enter n val : "))

for i in range(1, n + 1):
    if n % i == 0:
        print(f"{i} is factor")
```

Example:

``` text
Enter n val : 6
1 is factor
2 is factor
3 is factor
6 is factor
```

## Why `range(1, n + 1)`?

Python excludes the stop value of `range()`.

For example:

``` python
range(1, 6)
```

produces:

``` text
1, 2, 3, 4, 5
```

To include `6`, we need:

``` python
range(1, 7)
```

Therefore, when `n` is stored in a variable, we use:

``` python
range(1, n + 1)
```

# 3. Count the Factors

Instead of printing each factor, we can count how many factors the
number has.

``` python
n = int(input("Enter n val : "))

count = 0

for i in range(1, n + 1):
    if n % i == 0:
        count += 1

print(f"Count : {count}")
```

For:

``` text
Enter n val : 6
```

the result is:

``` text
Count : 4
```

because the factors are:

``` text
1, 2, 3, 6
```

For:

``` text
Enter n val : 11
```

the result is:

``` text
Count : 2
```

because the only factors are:

``` text
1, 11
```

------------------------------------------------------------------------

# 4. How the Counter Works

The counter starts at zero:

``` python
count = 0
```

Every time a factor is discovered:

``` python
count += 1
```

This is equivalent to:

``` python
count = count + 1
```

For `n = 6`:

    i   `6 % i` Factor?     Count
  --- --------- --------- -------
    1         0 Yes             1
    2         0 Yes             2
    3         0 Yes             3
    4         2 No              3
    5         1 No              3
    6         0 Yes             4

Final count:

``` text
4
```

# 5. Prime Numbers

A **prime number** is a positive integer greater than `1` that has
exactly two positive factors:

``` text
1 and itself
```

Examples include:

``` text
2, 3, 5, 7, 11, 13, 17, ...
```

Consider `11`.

Its factors are:

``` text
1, 11
```

Factor count:

``` text
2
```

Therefore:

``` text
11 is Prime
```

Now consider `6`.

Its factors are:

``` text
1, 2, 3, 6
```

Factor count:

``` text
4
```

Therefore:

``` text
6 is not Prime
```

------------------------------------------------------------------------

# 6. Prime Number Program

The lecture builds the prime-number checker from the factor-counting
program.

``` python
n = int(input("Enter n val : "))

count = 0

for i in range(1, n + 1):
    if n % i == 0:
        count += 1

if count == 2:
    print(f"{n} is Prime")
else:
    print(f"{n} is not Prime")
```

Example:

``` text
Enter n val : 11
11 is Prime
```

Another example:

``` text
Enter n val : 6
6 is not Prime
```

The important condition is:

``` python
count == 2
```

because prime numbers have exactly two factors.

------------------------------------------------------------------------

# 7. Prime Number Edge Case

The number `1` is **not** prime.

Its only positive factor is:

``` text
1
```

so its factor count is `1`, not `2`.

A slightly more explicit version is:

``` python
n = int(input("Enter n val : "))

count = 0

for i in range(1, n + 1):
    if n % i == 0:
        count += 1

if n > 1 and count == 2:
    print(f"{n} is Prime")
else:
    print(f"{n} is not Prime")
```

# 8. Sum of Factors

The next idea is to add factors instead of counting them.

``` python
n = int(input("Enter n val : "))

total = 0

for i in range(1, n + 1):
    if n % i == 0:
        total += i

print(f"Sum of factors : {total}")
```

For `6`:

``` text
Factors = 1, 2, 3, 6
```

Therefore:

``` text
1 + 2 + 3 + 6 = 12
```

Output:

``` text
Sum of factors : 12
```

------------------------------------------------------------------------

# 9. Counter vs Accumulator

Both programs use the same factor condition:

``` python
if n % i == 0:
```

But what happens afterward is different.

## Counter

``` python
count += 1
```

This answers:

> How many factors are there?

## Accumulator

``` python
total += i
```

This answers:

> What is the sum of the factors?

Example:

``` python
n = 6
count = 0
total = 0

for i in range(1, n + 1):
    if n % i == 0:
        count += 1
        total += i

print(f"Count : {count}")
print(f"Sum   : {total}")
```

Output:

``` text
Count : 4
Sum   : 12
```

------------------------------------------------------------------------

# 10. Perfect Numbers

A **perfect number** is a positive integer equal to the sum of its
**proper factors**.

Proper factors are all positive factors except the number itself.

Consider:

``` text
n = 6
```

All factors:

``` text
1, 2, 3, 6
```

Exclude `6` itself:

``` text
1, 2, 3
```

Now calculate:

``` text
1 + 2 + 3 = 6
```

Since the sum equals the original number:

``` text
6 is Perfect
```

------------------------------------------------------------------------

# 11. Why `range(1, n)` Is Used for Perfect Numbers

When checking whether a number is perfect, the number itself must not be
included in the sum.

Therefore, the lecture uses:

``` python
range(1, n)
```

instead of:

``` python
range(1, n + 1)
```

For `n = 6`:

``` python
range(1, 6)
```

generates:

``` text
1, 2, 3, 4, 5
```

The number `6` itself is automatically excluded.

------------------------------------------------------------------------

# 12. Perfect Number Program

``` python
n = int(input("Enter n val : "))

total = 0

for i in range(1, n):
    if n % i == 0:
        total += i

if total == n:
    print(f"{n} is Perfect")
else:
    print(f"{n} is not Perfect")
```

Example:

``` text
Enter n val : 6
6 is Perfect
```

------------------------------------------------------------------------

# 13. Step-by-Step Perfect Number Example

For:

``` text
n = 6
```

the loop checks:

``` text
1, 2, 3, 4, 5
```

The factors among them are:

``` text
1, 2, 3
```

The accumulator changes like this:

``` text
total = 0

total = 0 + 1
      = 1

total = 1 + 2
      = 3

total = 3 + 3
      = 6
```

Finally:

``` python
if total == n:
```

becomes:

``` python
if 6 == 6:
```

which is true.

Therefore:

``` text
6 is Perfect
```

# 16. Relationship Between the Programs

These programs are closely related.

The common factor test is:

``` python
n % i == 0
```

Then we decide what to do when the condition is true.

### Print a factor

``` python
if n % i == 0:
    print(i)
```

### Count a factor

``` python
if n % i == 0:
    count += 1
```

### Add a factor

``` python
if n % i == 0:
    total += i
```

This is an important programming pattern: the same loop and condition
can solve different problems depending on the operation performed inside
the `if` block.

# 17. Combined Factor Program

We can print, count, and sum all factors in one program.

``` python
n = int(input("Enter n val : "))

count = 0
total = 0

print(f"Factors of {n}:")

for i in range(1, n + 1):
    if n % i == 0:
        print(i)
        count += 1
        total += i

print(f"Number of factors : {count}")
print(f"Sum of factors    : {total}")
```

For `6`:

``` text
Enter n val : 6
Factors of 6:
1
2
3
6
Number of factors : 4
Sum of factors    : 12
```

# 18. Combined Prime and Perfect Checker

The concepts can also be combined:

``` python
n = int(input("Enter n val : "))

factor_count = 0
proper_factor_sum = 0

for i in range(1, n + 1):
    if n % i == 0:
        factor_count += 1

        if i != n:
            proper_factor_sum += i

if n > 1 and factor_count == 2:
    print(f"{n} is Prime")
else:
    print(f"{n} is not Prime")

if n > 0 and proper_factor_sum == n:
    print(f"{n} is Perfect")
else:
    print(f"{n} is not Perfect")
```

For:

``` text
n = 6
```

output:

``` text
6 is not Prime
6 is Perfect
```

For:

``` text
n = 11
```

output:

``` text
11 is Prime
11 is not Perfect
```

# 19. Important Python Concepts Used

## Modulus `%`

The modulus operator returns the remainder:

``` python
10 % 3
```

Result:

``` text
1
```

A number `i` is a factor of `n` when:

``` python
n % i == 0
```

------------------------------------------------------------------------

## `range(1, n + 1)`

Use this when `n` itself should be checked:

``` python
for i in range(1, n + 1):
```

Useful for:

-   printing all factors;
-   counting all factors;
-   prime-number checking.

------------------------------------------------------------------------

## `range(1, n)`

Use this when `n` itself should be excluded:

``` python
for i in range(1, n):
```

Useful for:

-   proper factors;
-   perfect-number checking.

------------------------------------------------------------------------

# 20. Common Beginner Mistakes

## Mistake 1: Excluding `n` when finding all factors

``` python
for i in range(1, n):
```

This does not test `n`.

Use:

``` python
for i in range(1, n + 1):
```

when all factors are required.

## Mistake 2: Including `n` in the perfect-number sum

This includes the number itself:

``` python
for i in range(1, n + 1):
```

For the lecture's perfect-number algorithm, use:

``` python
for i in range(1, n):
```

## Mistake 3: Confusing counting and summing

Counting:

``` python
count += 1
```

Summing:

``` python
total += i
```

## Mistake 4: Forgetting initialization

Always initialize counters and accumulators:

``` python
count = 0
total = 0
```

## Mistake 5: Confusing `=` and `==`

Assignment:

``` python
count = 2
```

Comparison:

``` python
count == 2
```

A prime check requires:

``` python
if count == 2:
```

------------------------------------------------------------------------

# 21. Recommended Python Style

The lecture may show:

``` python
if(n%i==0):
```

It works, but this is easier to read:

``` python
if n % i == 0:
```

Likewise:

``` python
count+=1
```

is usually formatted as:

``` python
count += 1
```

For an accumulator, prefer:

``` python
total = 0
```

rather than:

``` python
sum = 0
```

because `sum()` is already a built-in Python function.

# 24. Summary

The lecture follows a useful progression:

``` text
Factors
   |
   +--> Print Factors
   |
   +--> Count Factors --> Prime Number
   |
   +--> Sum Proper Factors --> Perfect Number
```

Remember:

``` python
n % i == 0
```

means `i` is a factor of `n`.

For all factors:

``` python
range(1, n + 1)
```

For proper factors excluding `n`:

``` python
range(1, n)
```

A prime number has exactly:

``` text
2 factors
```

A perfect number satisfies:

``` text
sum of proper factors == number
```

These examples reinforce some of the most important beginner Python
concepts: `for` loops, `range()`, `%`, `if`, counters, accumulators, and
translating mathematical rules into program logic.
