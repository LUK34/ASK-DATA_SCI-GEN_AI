# Python Loops - `while`, `for`, `range()`, Counters and Accumulators

This chapter introduces two of the most important repetition mechanisms
in Python:

-   `while` loops
-   `for` loops
-   `range()`
-   `break`
-   counters
-   accumulators

The examples are based on the lecture screenshots and have been
rewritten as clean, copy-paste-ready Python.

------------------------------------------------------------------------

## 1. Why Do We Need Loops?

A **loop** lets a program execute a block of code repeatedly.

Instead of writing:

``` python
print(1)
print(2)
print(3)
print(4)
print(5)
```

we can write:

``` python
for i in range(1, 6):
    print(i)
```

Output:

``` text
1
2
3
4
5
```

Loops are especially useful when:

-   the same operation must run many times;
-   data must be processed repeatedly;
-   a program should continue until the user chooses to stop;
-   we need to count or calculate values across a sequence.

# Part 1 - `while` Loops

## 2. Basic `while` Loop

A `while` loop repeats its body while its condition remains `True`.

``` python
while condition:
    # code to repeat
```

A common pattern in interactive programs is:

``` python
while True:
    # perform some work

    if some_condition:
        break
```

`while True` creates an intentionally continuous loop. The `break`
statement is then used to exit it.

------------------------------------------------------------------------

## 3. Repeating an Addition Program

The lecture demonstrates a program that repeatedly asks for two numbers
and adds them.

``` python
while True:
    a = int(input("Enter First num : "))
    b = int(input("Enter Second num : "))

    c = a + b

    print(f"Sum = {c}")

    choice = input("Do you stop(y/n) : ")

    if choice == "y":
        break
```

Example:

``` text
Enter First num : 12
Enter Second num : 13
Sum = 25
Do you stop(y/n) : n

Enter First num : 23
Enter Second num : 34
Sum = 57
Do you stop(y/n) : n

Enter First num : 56
Enter Second num : 78
Sum = 134
Do you stop(y/n) : y
```

### How it works

The loop begins with:

``` python
while True:
```

so Python keeps executing the block.

After each calculation, the program asks:

``` python
choice = input("Do you stop(y/n) : ")
```

If the user enters `y`:

``` python
if choice == "y":
    break
```

`break` immediately terminates the loop.

------------------------------------------------------------------------

## 4. Checking Even and Odd Numbers Repeatedly

The same technique can be used for an even/odd checker.

``` python
while True:
    n = int(input("Enter num : "))

    if n % 2 == 0:
        print(f"{n} is Even")
    else:
        print(f"{n} is not Even")

    choice = input("Do you continue(y/n) : ")

    if choice == "n":
        break
```

Example:

``` text
Enter num : 13
13 is not Even
Do you continue(y/n) : y

Enter num : 22
22 is Even
Do you continue(y/n) : y

Enter num : 45
45 is not Even
Do you continue(y/n) : n
```

### Understanding `%`

The `%` operator gives the remainder after division.

``` python
22 % 2
```

returns:

``` text
0
```

Therefore:

``` python
n % 2 == 0
```

means that `n` is divisible by 2 and is therefore even.

# Part 2 - Menu-Driven Programs

## 5. Calculator Using `while True`

A practical use of a `while` loop is a menu-driven program.

``` python
while True:
    print("1. Add")
    print("2. Subtract")
    print("3. Multiply")
    print("4. Exit")

    choice = int(input("Enter choice : "))

    if choice == 1:
        print("Enter 2 nums to add : ")
        a = int(input())
        b = int(input())
        print(f"Sum = {a + b}")

    elif choice == 2:
        print("Enter 2 nums to subtract : ")
        a = int(input())
        b = int(input())
        print(f"Difference = {a - b}")

    elif choice == 3:
        print("Enter 2 nums to multiply : ")
        a = int(input())
        b = int(input())
        print(f"Product = {a * b}")

    elif choice == 4:
        print("End")
        break

    else:
        print("Error : Invalid choice")
```

Example interaction:

``` text
1. Add
2. Subtract
3. Multiply
4. Exit
Enter choice : 3

Enter 2 nums to multiply :
5
8
Product = 40
```

If the user enters an unsupported option:

``` text
Enter choice : 9
Error : Invalid choice
```

The menu then appears again because the program is still inside
`while True`.

If the user enters:

``` text
Enter choice : 4
End
```

the `break` statement ends the program.

### Important structure

``` python
if condition:
    ...

elif condition:
    ...

elif condition:
    ...

else:
    ...
```

Only the first matching branch is executed.

# Part 3 - `for` Loops

## 6. Introduction to `for`

A `for` loop is useful when we want to iterate over a known sequence of
values.

A common form is:

``` python
for i in range(...):
    print(i)
```

Unlike the previous `while True` examples, we normally do not need to
manually control when a basic `for` loop stops. The sequence produced by
`range()` determines the iterations.

------------------------------------------------------------------------

# Part 4 - Understanding `range()`

## 7. `range(start, stop, step)`

The general form is:

``` python
range(start, stop, step)
```

The parameters mean:

-   `start` - where the sequence begins;
-   `stop` - where it stops;
-   `step` - how much the value changes each time.

Two extremely important rules are:

> `start` is included.

> `stop` is excluded.

If `start` is omitted, Python uses `0`.

If `step` is omitted, Python uses `1`.

------------------------------------------------------------------------

## 8. `range(5)`

``` python
for i in range(5):
    print(i)
```

Values generated:

``` text
0
1
2
3
4
```

Conceptually:

``` text
range(5) => 0, 1, 2, 3, 4
```

It does **not** include `5`.

------------------------------------------------------------------------

## 9. `range(3, 8)`

``` python
for i in range(3, 8):
    print(i)
```

Values:

``` text
3
4
5
6
7
```

Therefore:

``` text
range(3, 8) => 3, 4, 5, 6, 7
```

Again, `8` is excluded.

------------------------------------------------------------------------

## 10. Using a Step Value

Consider:

``` python
range(2, 15, 4)
```

This means:

-   start at `2`;
-   stop before `15`;
-   increase by `4`.

Values:

``` text
2, 6, 10, 14
```

Code:

``` python
for i in range(2, 15, 4):
    print(i)
```

------------------------------------------------------------------------

# Part 5 - Counting Backwards

## 11. Negative Step

A negative step makes `range()` move backwards.

For example:

``` python
range(5, 0, -1)
```

produces:

``` text
5, 4, 3, 2, 1
```

The stop value `0` is excluded.

To include `0`, we can use:

``` python
range(5, -1, -1)
```

which produces:

``` text
5, 4, 3, 2, 1, 0
```

### Key idea

When moving forward:

``` python
range(1, 6, 1)
```

the step is positive.

When moving backward:

``` python
range(5, 0, -1)
```

the step must be negative.

# Part 7 - User-Controlled Ranges

## 14. Print 1 to `n` and `n` to 1

Instead of hardcoding `10`, we can ask the user for the maximum value.

``` python
n = int(input("Enter n val : "))

print("1-n nums : ")

for i in range(1, n + 1, 1):
    print(f"i val : {i}")

print("n-1 nums : ")

for j in range(n, 0, -1):
    print(f"j val : {j}")
```

If the user enters:

``` text
4
```

the output is:

``` text
1-n nums :
i val : 1
i val : 2
i val : 3
i val : 4

n-1 nums :
j val : 4
j val : 3
j val : 2
j val : 1
```

### Why `n + 1`?

Suppose:

``` python
n = 4
```

Using:

``` python
range(1, 4)
```

would generate only:

``` text
1, 2, 3
```

To include `4`, we use:

``` python
range(1, n + 1)
```

which becomes:

``` python
range(1, 5)
```

and generates:

``` text
1, 2, 3, 4
```

# Part 8 - Start and End Values from the User

## 15. Print from `begin` to `end`

The lecture extends the previous idea by allowing the user to provide
both boundaries.

``` python
begin = int(input("Where to Start : "))
end = int(input("Where to Stop : "))

print("Begin to End : ")

for i in range(begin, end + 1, 1):
    print(f"i val : {i}")

print("End to Begin : ")

for j in range(end, begin - 1, -1):
    print(f"j val : {j}")
```

Example:

``` text
Where to Start : 13
Where to Stop : 18
```

Forward output:

``` text
Begin to End :
i val : 13
i val : 14
i val : 15
i val : 16
i val : 17
i val : 18
```

Backward output:

``` text
End to Begin :
j val : 18
j val : 17
j val : 16
j val : 15
j val : 14
j val : 13
```

### Why `begin - 1`?

For the reverse loop:

``` python
range(end, begin - 1, -1)
```

the stop value is still excluded.

If `begin` is `13`, the stop is:

``` text
12
```

Therefore Python generates down to `13` and stops before reaching `12`.

`for` loops are ideal for multiplication tables.

``` python
n = int(input("Enter table num : "))

for i in range(1, 11):
    print(f"{n} * {i} = {n * i}")
```

If the user enters:

``` text
13
```

the output is:

``` text
13 * 1 = 13
13 * 2 = 26
13 * 3 = 39
13 * 4 = 52
13 * 5 = 65
13 * 6 = 78
13 * 7 = 91
13 * 8 = 104
13 * 9 = 117
13 * 10 = 130
```

The loop variable `i` takes the values `1` through `10`.

On every iteration Python calculates:

``` python
n * i
```

# Part 10 - Filtering Values in a Loop

## 17. Print Even Numbers from 1 to 10

We can combine a `for` loop with an `if` statement.

``` python
for i in range(1, 11):
    if i % 2 == 0:
        print(f"i val : {i}")
```

Output:

``` text
i val : 2
i val : 4
i val : 6
i val : 8
i val : 10
```

The loop visits every number from `1` through `10`, but the `print()`
statement runs only when:

``` python
i % 2 == 0
```

is `True`.

# Part 11 - Counters

## 18. Count the Even Numbers from 1 to 10

Sometimes we do not want to print the values. Instead, we want to know
**how many** values satisfy a condition.

This is where a counter is useful.

``` python
count = 0

for i in range(1, 11):
    if i % 2 == 0:
        count += 1

print(f"Count is : {count}")
```

Output:

``` text
Count is : 5
```

The even numbers are:

``` text
2, 4, 6, 8, 10
```

so the final count is `5`.

### Understanding `count += 1`

This:

``` python
count += 1
```

is shorthand for:

``` python
count = count + 1
```

Starting with:

``` python
count = 0
```

the counter changes as follows:

``` text
0
1
2
3
4
5
```

It increments only when an even number is found.

# Part 12 - Accumulators

## 19. Sum the Even Numbers from 1 to 10

A **counter** counts how many items we found.

An **accumulator** adds the actual values together.

``` python
sum = 0

for i in range(1, 11):
    if i % 2 == 0:
        sum = sum + i

print(f"Sum is : {sum}")
```

Output:

``` text
Sum is : 30
```

The calculation is:

``` text
2 + 4 + 6 + 8 + 10 = 30
```

A more Python-friendly variable name is `total`, because `sum` is also
the name of Python's built-in `sum()` function:

``` python
total = 0

for i in range(1, 11):
    if i % 2 == 0:
        total += i

print(f"Sum is : {total}")
```

This version is recommended.

------------------------------------------------------------------------

# Counter vs Accumulator

These concepts look similar but solve different problems.

  Concept       Purpose                Typical Update
  ------------- ---------------------- ------------------
  Counter       Counts occurrences     `count += 1`
  Accumulator   Adds values together   `total += value`

Example:

``` python
count = 0
total = 0

for i in range(1, 11):
    if i % 2 == 0:
        count += 1
        total += i

print(f"Number of even values: {count}")
print(f"Sum of even values: {total}")
```

Output:

``` text
Number of even values: 5
Sum of even values: 30
```

# Important Concepts from This Lecture

## `break`

`break` immediately terminates the nearest loop.

``` python
while True:
    choice = input("Exit? (y/n): ")

    if choice == "y":
        break
```

------------------------------------------------------------------------

## `range()` Does Not Include the Stop Value

This is one of the most important rules to remember.

``` python
range(1, 5)
```

produces:

``` text
1, 2, 3, 4
```

not:

``` text
1, 2, 3, 4, 5
```

To include `5`:

``` python
range(1, 6)
```

------------------------------------------------------------------------

## Positive and Negative Steps

Forward:

``` python
range(1, 6, 1)
```

``` text
1, 2, 3, 4, 5
```

Backward:

``` python
range(5, 0, -1)
```

``` text
5, 4, 3, 2, 1
```

------------------------------------------------------------------------

## Indentation Matters

Python uses indentation to determine which statements belong to a loop
or condition.

Correct:

``` python
for i in range(1, 6):
    if i % 2 == 0:
        print(i)
```

Incorrect:

``` python
for i in range(1, 6):
if i % 2 == 0:
print(i)
```

The incorrect version produces an indentation-related syntax error.

# Common Beginner Mistakes

### Mistake 1 - Expecting the stop value to be included

``` python
for i in range(1, 10):
    print(i)
```

This prints only `1` through `9`.

For `1` through `10`, use:

``` python
for i in range(1, 11):
    print(i)
```

### Mistake 2 - Using a positive step when counting backward

This does not produce the intended countdown:

``` python
range(10, 0, 1)
```

Use:

``` python
range(10, 0, -1)
```

### Mistake 3 - Forgetting `break` in an intentional infinite loop

``` python
while True:
    print("Running")
```

This continues indefinitely unless the program is interrupted.

Normally an interactive `while True` program needs a reachable exit
condition:

``` python
while True:
    choice = input("Continue? ")

    if choice == "n":
        break
```

### Mistake 4 - Forgetting to initialize a counter or accumulator

Incorrect:

``` python
for i in range(1, 11):
    count += 1
```

`count` does not yet exist.

Correct:

``` python
count = 0

for i in range(1, 11):
    count += 1
```

# Summary

In this chapter we learned that:

-   `while` repeats code while a condition remains true.
-   `while True` can create a continuous interactive program.
-   `break` exits a loop.
-   `for` is convenient for iterating over a sequence.
-   `range()` commonly controls numeric `for` loops.
-   `range(start, stop, step)` includes `start` but excludes `stop`.
-   Positive steps move forward.
-   Negative steps move backward.
-   `if` can filter values while looping.
-   A **counter** records how many times something happens.
-   An **accumulator** builds a running total.

These concepts form the foundation for more advanced Python topics such
as nested loops, collections, functions, file processing, data
processing, and automation.
