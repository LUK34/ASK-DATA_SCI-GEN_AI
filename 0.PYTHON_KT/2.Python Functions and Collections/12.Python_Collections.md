# 1. Python Collection Data Types

A collection data type allows us to keep multiple values inside a single variable.

Python commonly uses four built-in collection types:

| Type | Duplicates | Ordered | Index Based | Mutable |
|---|---|---|---|---|
| `list` | Yes | Yes | Yes | Yes |
| `tuple` | Yes | Yes | Yes | No |
| `set` | No | No guaranteed positional order | No | Yes |
| `dict` | Keys must be unique; values may repeat | Insertion ordered in modern Python | Accessed by keys | Yes |

> **Mutable** means the object can be changed after creation. **Immutable** means its elements cannot be changed in place after creation.

# 2. Lists

A **list** stores multiple values inside square brackets `[]`.

```python
nums = [10, 20, 10, 30, 20]
```

Important list properties:

- Duplicates are allowed.
- Elements preserve their order.
- Elements can be accessed using indexes.
- Lists are mutable.

## 2.1 Accessing a List Element

Python indexing starts from `0`.

```python
nums = [10, 20, 10, 30, 20]

print(nums[2])
```

Output:

```text
10
```

## 2.2 Modifying a List

Because lists are mutable, an element can be replaced using its index.

```python
nums = [10, 20, 10, 30, 20]
nums[2] = nums[2] + 5

print(nums)
```

Output:

```text
[10, 20, 15, 30, 20]
```

# 3. Common List Methods

Consider this initial list:

```python
nums = [10, 20, 30, 20]
print(f"List is : {nums}")
```

## 3.1 `append()` — Add at the End

```python
nums.append(50)
print(f"List is : {nums}")
```

Result:

```text
[10, 20, 30, 20, 50]
```

## 3.2 `insert()` — Insert at a Specific Index

```python
nums.insert(2, 25)
print(f"List is : {nums}")
```

`25` is inserted at index `2`.

```text
[10, 20, 25, 30, 20, 50]
```

## 3.3 Modify Using an Index

```python
nums[3] = nums[3] + 5
print(f"List is : {nums}")
```

Result:

```text
[10, 20, 25, 35, 20, 50]
```

## 3.4 `index()` — Find an Element's Index

```python
print(f"50 @ Index : {nums.index(50)}")
```

Output:

```text
50 @ Index : 5
```

`index()` returns the index of the **first matching occurrence**.

## 3.5 `count()` — Count Occurrences

```python
print(f"20 present : {nums.count(20)} times")
```

Output:

```text
20 present : 2 times
```

## 3.6 `sort()` — Sort the List

```python
nums.sort()
print(f"List is : {nums}")
```

Output:

```text
[10, 20, 20, 25, 35, 50]
```

By default, numeric values are sorted in ascending order.

## 3.7 `reverse()` — Reverse Current Order

```python
nums.reverse()
print(f"List is : {nums}")
```

Output:

```text
[50, 35, 25, 20, 20, 10]
```

> `reverse()` reverses the existing order. It is not the same operation as sorting in descending order, although after an ascending `sort()` the result looks descending.

## 3.8 `pop()` — Remove an Element

Without an argument, `pop()` removes and returns the last element.

```python
nums.pop()
print(f"List is : {nums}")
```

You can also remove the element at a specific index:

```python
nums.pop(2)
print(f"List is : {nums}")
```

## 3.9 `remove()` — Remove by Value

```python
nums.remove(20)
print(f"List is : {nums}")
```

If the value occurs more than once, `remove()` deletes only the **first matching occurrence**.

## 3.10 `clear()` — Remove All Elements

```python
nums.clear()
print(f"List is : {nums}")
```

Output:

```text
[]
```

The list object still exists, but it is empty.

## 3.11 `del` — Delete the Variable

```python
del nums
```

After this, `nums` itself no longer exists. Therefore this produces an error:

```python
print(nums)
```

Typical error:

```text
NameError: name 'nums' is not defined
```

### `clear()` vs `del`

```python
nums.clear()
```

keeps the variable but empties its list.

```python
del nums
```

deletes the variable binding itself.

# 4. Nested Lists

A list can contain another list.

```python
nums = [10, 20, 30, [30, 40, 50], 60]
```

The outer list indexes are conceptually:

```text
Index:   0   1   2        3         4
Value:  10  20  30  [30, 40, 50]  60
```

## 4.1 Accessing Outer Elements

```python
print(nums[1])
```

Output:

```text
20
```

```python
print(nums[3])
```

Output:

```text
[30, 40, 50]
```

Negative indexing works as well:

```python
print(nums[-1])
```

Output:

```text
60
```

## 4.2 Accessing the Inner List

The nested list is located at `nums[3]`.

```python
print(nums[3][0])
```

Output:

```text
30
```

```python
print(nums[3][-1])
```

Output:

```text
50
```

Think of:

```python
nums[3][0]
```

as:

1. `nums[3]` → get `[30, 40, 50]`
2. `[0]` → get the first element from that inner list

## 4.3 Slicing the Inner List

```python
print(nums[3][0:2])
```

Output:

```text
[30, 40]
```

```python
print(nums[3][1:3])
```

Output:

```text
[40, 50]
```

Remember: the stop index in slicing is **excluded**.

# 5. Tuples

A **tuple** is commonly written using parentheses `()`.

```python
nums = (10, 20, 30, 20, 30)
```

Important tuple properties:

- Duplicates are allowed.
- Tuples are ordered.
- Tuples support indexing.
- Tuples are immutable.

## 5.1 Accessing Tuple Elements

```python
nums = (10, 20, 30)
print(nums[2])
```

Output:

```text
30
```

## 5.2 Why Tuple Modification Fails

```python
nums = (10, 20, 30)
nums[1] = nums[1] + 5
```

This raises a `TypeError` similar to:

```text
TypeError: 'tuple' object does not support item assignment
```

This happens because tuples are immutable.

# 6. Sets

A **set** stores unique elements.

```python
nums = {10, 20, 30, 40, 50, 40, 30, 50, 20}
print(nums)
```

Repeated values are automatically removed conceptually, so the set contains only:

```text
10, 20, 30, 40, 50
```

The displayed order should **not be relied upon**.

Important set properties:

- Duplicate values are not stored.
- Sets are not positional/index-based collections.
- Sets are mutable.
- Elements can be added and removed.

## 6.1 Sets Do Not Support Indexing

This is invalid:

```python
print(nums[2])
```

A set has no meaningful positional index such as "element at index 2".

## 6.2 `add()`

```python
nums.add(25)
print(f"Set is : {nums}")
```

`add()` inserts an element into the set if it is not already present.

## 6.3 `discard()`

```python
nums.discard(30)
print(f"Set is : {nums}")
```

`discard()` removes the value when it exists. If the value is absent, it does not raise a `KeyError`.

# 7. Set Operations

Consider:

```python
s1 = {1, 2, 3, 4}
s2 = {3, 4, 5, 6}
```

Conceptually:

```text
s1 only      common       s2 only
 1, 2         3, 4         5, 6
```

## 7.1 Union

Union returns all unique values present in either set.

```python
print(s1.union(s2))
```

Equivalent operator syntax:

```python
print(s1 | s2)
```

Result contains:

```text
{1, 2, 3, 4, 5, 6}
```

## 7.2 Intersection

Intersection returns values common to both sets.

```python
print(s1.intersection(s2))
```

Equivalent:

```python
print(s1 & s2)
```

Result:

```text
{3, 4}
```

## 7.3 Difference

Values in `s1` but not in `s2`:

```python
print(s1.difference(s2))
```

Result:

```text
{1, 2}
```

The direction matters:

```python
print(s2.difference(s1))
```

Result:

```text
{5, 6}
```

## 7.4 Symmetric Difference

Symmetric difference returns elements belonging to one set or the other, but **not both**.

```python
print(s1.symmetric_difference(s2))
```

Result contains:

```text
{1, 2, 5, 6}
```

Equivalent operator:

```python
print(s1 ^ s2)
```

# 8. Dictionaries

A **dictionary** stores information as **key-value pairs**.

A valid Python dictionary looks like this:

```python
data = {
    "name": "Amar",
    "age": 23,
    "height": 5.9
}
```

Important dictionary properties:

- Data is stored as `key: value` pairs.
- Keys must be unique.
- Values can be duplicated.
- Dictionaries are mutable.
- Values are normally accessed using keys rather than numeric positions.

> In actual Python code, string keys such as `"name"` must be quoted. This corrects the shorthand notation shown in the lecture diagram.

---

# 9. Working with Dictionaries

Create a student dictionary:

```python
student = {
    "id": 101,
    "name": "Amar",
    "age": 23
}

print(student)
```

## 9.1 Accessing Values Using Keys

```python
print(f"Name is : {student['name']}")
print(f"Age is : {student['age']}")
```

Output:

```text
Name is : Amar
Age is : 23
```

## 9.2 Adding a New Key-Value Pair

```python
student["course"] = "Python"
print(student)
```

Now the dictionary contains the additional `course` entry.

## 9.3 Updating an Existing Value

```python
student["age"] = 21
print(student)
```

Because dictionaries are mutable, the value associated with `age` changes from `23` to `21`.

## 9.4 `keys()`

```python
print(student.keys())
```

This returns a dictionary view containing the keys.

Conceptually:

```text
id, name, age, course
```

## 9.5 `values()`

```python
print(student.values())
```

Conceptually:

```text
101, Amar, 21, Python
```

## 9.6 Loop Through Keys

```python
print("Key by Key : ")

for key in student:
    print(key)
```

Output:

```text
id
name
age
course
```

## 9.7 Loop Through Keys and Values

The lecture demonstrates looking up each value using its key:

```python
print("Key and Value : ")

for key in student:
    print(f"{key} : {student[key]}")
```

Output:

```text
id : 101
name : Amar
age : 21
course : Python
```

A commonly used alternative is `items()`:

```python
for key, value in student.items():
    print(f"{key} : {value}")
```

# 10. Normal Functions

A function is a reusable block of code.

The screenshot demonstrates a function with **no arguments** and no useful returned value:

```python
def hello():
    print("Hello all")
    return

hello()
```

Output:

```text
Hello all
```

## Understanding the Code

```python
def hello():
```

defines the function.

```python
print("Hello all")
```

is executed when the function is called.

```python
hello()
```

calls the function.

A bare `return` immediately exits the function and returns `None`. At the end of this particular function it is optional, so this is equivalent for practical purposes:

```python
def hello():
    print("Hello all")
```

# 11. Lambda Expressions

A **lambda expression** creates a small anonymous function using the `lambda` keyword.

The lecture example is:

```python
hi = lambda: print("Hi all")

hi()
```

Output:

```text
Hi all
```

Its normal-function equivalent is:

```python
def hi():
    print("Hi all")

hi()
```

The general lambda syntax is:

```python
lambda arguments: expression
```

For example:

```python
add = lambda a, b: a + b
print(add(10, 20))
```

Output:

```text
30
```

Lambdas are best suited to short expressions. For multi-step logic, a regular `def` function is usually clearer.

# 16. Common Beginner Mistakes

### Mistake 1 — Trying to Modify a Tuple

Incorrect:

```python
nums = (10, 20, 30)
nums[1] = 25
```

Tuples are immutable.

### Mistake 2 — Trying to Index a Set

Incorrect:

```python
nums = {10, 20, 30}
print(nums[1])
```

Sets do not support positional indexing.

### Mistake 3 — Using a Variable After `del`

```python
nums = [10, 20]
del nums
print(nums)
```

This raises `NameError` because the name was deleted.

### Mistake 4 — Forgetting That `remove()` Uses a Value

```python
nums.remove(20)
```

This removes the first value `20`.

By contrast:

```python
nums.pop(2)
```

removes the element at index `2`.

### Mistake 5 — Assuming Set Output Order

Do not write logic that depends on a set printing in a particular order.

# 18. Key Takeaways

Python's collection types solve different problems. A **list** is flexible and index-based; a **tuple** is index-based but immutable; a **set** focuses on unique values and mathematical set operations; and a **dictionary** associates unique keys with values.

The most important beginner distinction is between **mutable** and **immutable** objects. Lists, sets, and dictionaries can be modified after creation. Tuples cannot have their elements reassigned.

You should also distinguish between operations that work by **index** and those that work by **value**. For example, `pop(2)` removes the list element at index `2`, while `remove(20)` searches for the first value equal to `20`.

Finally, nested collections are accessed one level at a time. In `nums[3][0]`, Python first retrieves the object at outer index `3`, then retrieves index `0` from that inner object.
