# 1. Recursion

## 1.1 What is Recursion?

**Recursion** is a programming technique where a function calls itself.

A recursive solution normally contains:

-   a **base case** --- the condition that stops recursion;
-   a **recursive case** --- the part where the function calls itself
    with a smaller/simpler problem.

Without a suitable base case, the function can continue calling itself
until Python raises a `RecursionError`.

------------------------------------------------------------------------

# 2. Recursive Factorial

The lecture demonstrates factorial using recursion.

For a positive integer `n`:

``` text
n! = n × (n-1) × (n-2) × ... × 1
```

For example:

``` text
4! = 4 × 3 × 2 × 1 = 24
```

By definition:

``` text
0! = 1
1! = 1
```

## 2.1 Python Program

``` python
def fact(n):
    if n == 1 or n == 0:
        return 1
    else:
        return n * fact(n - 1)


res = fact(4)
print(res)
```

Output:

``` text
24
```

## 2.2 How `fact(4)` Works

When Python executes:

``` python
fact(4)
```

the calls expand as follows:

``` text
fact(4)
= 4 * fact(3)

= 4 * (3 * fact(2))

= 4 * (3 * (2 * fact(1)))

= 4 * (3 * (2 * 1))

= 4 * (3 * 2)

= 4 * 6

= 24
```

The important point is that the recursive calls first move **downward**
toward the base case.

``` text
fact(4)
   ↓
fact(3)
   ↓
fact(2)
   ↓
fact(1)
```

At `fact(1)`, the base case executes:

``` python
return 1
```

The pending calculations can then resolve in the opposite direction:

``` text
fact(1) → 1
fact(2) → 2 × 1 = 2
fact(3) → 3 × 2 = 6
fact(4) → 4 × 6 = 24
```

This is an important mental model for understanding recursion.

# 3. Introduction to Python Lists

A **list** is a Python collection that can store multiple values in one
variable.

Example:

``` python
nums = [10, 20, 30, 40, 50]
```

Conceptually:

``` text
Value:           10    20    30    40    50
Positive index:   0     1     2     3     4
Negative index:  -5    -4    -3    -2    -1
```

Python uses **zero-based indexing**, meaning that the first element has
index `0`.

Negative indexes count from the end:

-   `-1` → last element
-   `-2` → second-last element
-   `-3` → third-last element

------------------------------------------------------------------------

# 4. Finding the Length of a List

Use the built-in `len()` function:

``` python
nums = [10, 20, 30, 40, 50]

print(f"List is : {nums}")
print(f"Length is : {len(nums)}")
```

Output:

``` text
List is : [10, 20, 30, 40, 50]
Length is : 5
```

`len(nums)` returns the number of elements, not the final index.

Therefore:

``` text
Length = 5
Last positive index = 4
```

A useful relationship is:

``` python
last_index = len(nums) - 1
```

------------------------------------------------------------------------

# 5. Accessing the First and Last Elements

``` python
nums = [10, 20, 30, 40, 50]

print(f"First element : {nums[0]}")
print(f"Last element : {nums[-1]}")
```

Output:

``` text
First element : 10
Last element : 50
```

You could also access the final element using:

``` python
nums[len(nums) - 1]
```

but `nums[-1]` is simpler and idiomatic Python.

------------------------------------------------------------------------

# 6. Traversing a List Using `range()`

Suppose:

``` python
nums = [10, 20, 30, 40, 50]
```

To print every element using its index:

``` python
print("List is : ")

for i in range(0, len(nums), 1):
    print(nums[i])
```

Output:

``` text
List is :
10
20
30
40
50
```

## Understanding `range()`

The general form is:

``` python
range(start, stop, step)
```

For:

``` python
range(0, len(nums), 1)
```

and a five-element list:

``` text
start = 0
stop  = 5
step  = 1
```

The generated indexes are:

``` text
0, 1, 2, 3, 4
```

The stop value `5` is **not included**.

------------------------------------------------------------------------

# 7. Traversing a List in Reverse

The lecture demonstrates reverse traversal using `range()`.

``` python
nums = [10, 20, 30, 40, 50]

print("Reverse List is : ")

for i in range(len(nums) - 1, -1, -1):
    print(nums[i])
```

Output:

``` text
Reverse List is :
50
40
30
20
10
```

For this list:

``` python
range(len(nums) - 1, -1, -1)
```

becomes:

``` python
range(4, -1, -1)
```

which generates:

``` text
4, 3, 2, 1, 0
```

Why is the stop value `-1`?

Because the stop value of `range()` is excluded. Using `-1` allows index
`0` to be processed before the loop stops.

# 8. List Indexing

**Indexing** allows us to access one individual element from a list.

``` python
nums = [10, 20, 30, 40, 50]

print(nums[0])
print(nums[2])
print(nums[-1])
print(nums[-3])
```

Output:

``` text
10
30
50
30
```

Explanation:

  Expression              Index   Result
  ------------ ---------------- --------
  `nums[0]`               first     `10`
  `nums[2]`               third     `30`
  `nums[-1]`               last     `50`
  `nums[-3]`     third from end     `30`

Trying to access an index outside the valid range raises an
`IndexError`.

------------------------------------------------------------------------

# 9. List Slicing

While indexing retrieves a **single element**, slicing retrieves a
**portion of a sequence**.

General syntax:

``` python
list[start:stop:step]
```

The `stop` position is excluded.

Using:

``` python
nums = [10, 20, 30, 40, 50]
```

## 9.1 Copy/Select the Entire List

``` python
print(nums[::])
```

Output:

``` text
[10, 20, 30, 40, 50]
```

Equivalent explicit form:

``` python
print(nums[0:len(nums):1])
```

Output:

``` text
[10, 20, 30, 40, 50]
```

Another equivalent form:

``` python
print(nums[:len(nums):])
```

Output:

``` text
[10, 20, 30, 40, 50]
```

When omitted:

-   `start` defaults appropriately to the beginning;
-   `stop` defaults appropriately to the end;
-   `step` normally defaults to `1`.

------------------------------------------------------------------------

# 10. Selecting Part of a List

Example:

``` python
print(nums[1:4:1])
```

Output:

``` text
[20, 30, 40]
```

Why is `50` not included?

Because the stop index `4` is excluded.

The slice processes indexes:

``` text
1, 2, 3
```

corresponding to:

``` text
20, 30, 40
```

------------------------------------------------------------------------

# 11. Selecting Alternate Elements

``` python
print(nums[0:len(nums):2])
```

Output:

``` text
[10, 30, 50]
```

Here the step is `2`, so Python selects:

``` text
index 0 → 10
index 2 → 30
index 4 → 50
```

A shorter version is:

``` python
print(nums[::2])
```

------------------------------------------------------------------------

# 12. Reversing a List with Slicing

Python provides a concise slicing technique:

``` python
print(nums[::-1])
```

Output:

``` text
[50, 40, 30, 20, 10]
```

The `-1` step tells Python to move backward through the list.

Compare:

``` python
nums[::1]     # forward
nums[::-1]    # backward
```

# 13. Iterating Directly Over List Elements

You do not always need indexes.

Instead of:

``` python
for i in range(0, len(nums), 1):
    print(nums[i])
```

you can write:

``` python
for x in nums:
    print(x)
```

Example:

``` python
nums = [10, 20, 30, 40, 50]

print("List : ")

for x in nums:
    print(x)
```

Output:

``` text
List :
10
20
30
40
50
```

For simple forward processing, direct iteration is usually clearer.

Use index-based iteration when you actually need the index.

# 14. Finding the Sum of All Elements

The lecture calculates the total manually using a loop.

``` python
nums = [3, 7, 4, 2, 9, 5, 8, 6]

sum = 0

for x in nums:
    sum = sum + x

print(f"Sum is : {sum}")
```

Output:

``` text
Sum is : 44
```

## How the accumulator works

Initially:

``` text
sum = 0
```

Then:

``` text
0  + 3 = 3
3  + 7 = 10
10 + 4 = 14
14 + 2 = 16
16 + 9 = 25
25 + 5 = 30
30 + 8 = 38
38 + 6 = 44
```

Final result:

``` text
44
```

### Professional Note

Although `sum` is used in the lecture, Python already has a built-in
function named `sum()`.

For production-style code, prefer a variable such as:

``` python
total = 0

for x in nums:
    total += x
```

Python can also calculate it directly:

``` python
total = sum(nums)
```

The manual loop remains important because it teaches the **accumulator
pattern**.

# 15. Printing Even Numbers from a List

``` python
nums = [3, 7, 4, 2, 9, 5, 8, 6]

print("Even nums :")

for x in nums:
    if x % 2 == 0:
        print(x)
```

Output:

``` text
Even nums :
4
2
8
6
```

## Why `% 2 == 0`?

The `%` operator calculates the remainder.

For an even number:

``` text
number ÷ 2 → remainder 0
```

Therefore:

``` python
x % 2 == 0
```

means:

> Check whether `x` is evenly divisible by 2.

------------------------------------------------------------------------

# 16. Counting Even Numbers

The lecture then extends the previous example by counting the matching
elements.

``` python
nums = [3, 7, 4, 2, 9, 5, 8, 6]

count = 0

for x in nums:
    if x % 2 == 0:
        count += 1

print(f"Even count : {count}")
```

Output:

``` text
Even count : 4
```

The even numbers are:

``` text
4, 2, 8, 6
```

so the count is:

``` text
4
```

This demonstrates another common accumulator pattern:

``` python
count += 1
```

which is equivalent to:

``` python
count = count + 1
```

# 17. Sum of Only the Even Numbers

Instead of counting the even values, we can add them.

``` python
nums = [3, 7, 4, 2, 9, 5, 8, 6]

sum = 0

for x in nums:
    if x % 2 == 0:
        sum = sum + x

print(f"Even nums sum : {sum}")
```

Output:

``` text
Even nums sum : 20
```

Calculation:

``` text
4 + 2 + 8 + 6 = 20
```

A cleaner variable name would be:

``` python
even_sum = 0

for x in nums:
    if x % 2 == 0:
        even_sum += x

print(f"Even nums sum : {even_sum}")
```

# 18. Finding the Largest and Smallest Elements Manually

The lecture demonstrates how to find minimum and maximum values without
immediately relying on `min()` and `max()`.

``` python
nums = [3, 7, 4, 2, 9, 5, 8, 6]

large = nums[0]
small = nums[0]

for i in range(1, len(nums)):
    if nums[i] > large:
        large = nums[i]

    if nums[i] < small:
        small = nums[i]

print(f"Largest ele : {large}")
print(f"Smallest ele : {small}")
```

Output:

``` text
Largest ele : 9
Smallest ele : 2
```

## 18.1 Why initialize using `nums[0]`?

The algorithm starts by assuming that the first element is both:

``` python
large = nums[0]
small = nums[0]
```

For the example:

``` text
large = 3
small = 3
```

Every remaining value is compared with those candidates.

## 18.2 Why start the loop at index `1`?

Because index `0` has already been used for initialization:

``` python
for i in range(1, len(nums)):
```

For eight elements, this examines indexes:

``` text
1, 2, 3, 4, 5, 6, 7
```

## 18.3 Largest-value logic

``` python
if nums[i] > large:
    large = nums[i]
```

Whenever a bigger value is discovered, `large` is replaced.

## 18.4 Smallest-value logic

``` python
if nums[i] < small:
    small = nums[i]
```

Whenever a smaller value is discovered, `small` is replaced.

For the sample data, the final values are:

``` text
large = 9
small = 2
```

### Built-in alternative

Python also provides:

``` python
print(max(nums))
print(min(nums))
```

However, implementing the algorithm manually is valuable for learning
iteration and comparison logic.

# 19. Complete List Example

The following program combines the major list concepts from the lecture.

``` python
nums = [3, 7, 4, 2, 9, 5, 8, 6]

print(f"List: {nums}")
print(f"Length: {len(nums)}")
print(f"First element: {nums[0]}")
print(f"Last element: {nums[-1]}")

print("\nForward:")
for x in nums:
    print(x)

print("\nReverse:")
for i in range(len(nums) - 1, -1, -1):
    print(nums[i])

total = 0
even_count = 0
even_sum = 0

large = nums[0]
small = nums[0]

for x in nums:
    total += x

    if x % 2 == 0:
        even_count += 1
        even_sum += x

    if x > large:
        large = x

    if x < small:
        small = x

print(f"\nTotal: {total}")
print(f"Even count: {even_count}")
print(f"Even sum: {even_sum}")
print(f"Largest: {large}")
print(f"Smallest: {small}")

print(f"Reversed using slicing: {nums[::-1]}")
```

Expected summary:

``` text
Total: 44
Even count: 4
Even sum: 20
Largest: 9
Smallest: 2
```

# 20. Indexing vs Slicing

A common beginner confusion is the difference between indexing and
slicing.

  Feature           Indexing               Slicing
  ----------------- ---------------------- ------------------------------
  Purpose           Retrieve one element   Retrieve a range of elements
  Syntax            `nums[index]`          `nums[start:stop:step]`
  Example           `nums[2]`              `nums[1:4]`
  Typical result    `30`                   `[20, 30, 40]`
  Negative values   Supported              Supported

Example:

``` python
nums = [10, 20, 30, 40, 50]

print(nums[2])
print(nums[1:4])
```

Output:

``` text
30
[20, 30, 40]
```

# 21. Three Important Loop Patterns

The screenshots demonstrate three patterns that appear repeatedly in
real programs.

## Pattern 1 --- Process every element

``` python
for x in nums:
    print(x)
```

## Pattern 2 --- Accumulate a value

``` python
total = 0

for x in nums:
    total += x
```

## Pattern 3 --- Filter using a condition

``` python
for x in nums:
    if x % 2 == 0:
        print(x)
```

These patterns can be combined:

``` python
even_sum = 0

for x in nums:
    if x % 2 == 0:
        even_sum += x
```

Understanding these patterns is more important than memorizing
individual programs.

# 22. Common Beginner Mistakes

### Mistake: Confusing length with last index

For:

``` python
nums = [10, 20, 30, 40, 50]
```

`len(nums)` is `5`, but `nums[5]` is invalid.

The last valid positive index is:

``` python
len(nums) - 1
```

which is `4`.

### Mistake: Forgetting that slice stop is excluded

``` python
nums[1:4]
```

uses indexes:

``` text
1, 2, 3
```

not index `4`.

### Mistake: Incorrect reverse `range()`

Correct:

``` python
range(len(nums) - 1, -1, -1)
```

The negative step is essential.

### Mistake: Recursion without a base case

A recursive function must eventually reach a stopping condition.

### Mistake: Using `sum` as a variable name

This works:

``` python
sum = 0
```

but it shadows Python's built-in `sum()` function. Prefer:

``` python
total = 0
```

or:

``` python
even_sum = 0
```

def fact(n):

# 24. Key Takeaways

-   **Recursion** occurs when a function calls itself.
-   Every practical recursive function needs a **base case**.
-   `fact(4)` recursively reaches `fact(1)` and then returns values back
    through the pending calls.
-   Python lists use **zero-based indexing**.
-   Negative indexes access values from the end of a list.
-   `len(list)` returns the number of elements.
-   **Indexing** retrieves one element.
-   **Slicing** retrieves a range of elements.
-   Slice syntax is `start:stop:step`, and `stop` is excluded.
-   `nums[::-1]` is a convenient way to reverse a list.
-   `for x in nums` is a clean way to process elements directly.
-   `range()` is useful when indexes or reverse index traversal are
    required.
-   Accumulator variables can calculate totals and counts.
-   `% 2 == 0` identifies even numbers.
-   Largest and smallest values can be determined manually by comparison
    or with `max()` and `min()`.

These concepts form an important foundation for later Python topics such
as tuples, sets, dictionaries, comprehensions, algorithms, data
processing, and object-oriented programming.
