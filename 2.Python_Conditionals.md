# 1. Salary Calculation Using Percentages

Before moving into conditional statements, the lecture demonstrates a
practical arithmetic example: calculating an employee's total salary
from a basic salary.

The example uses:

-   HRA = 13% of basic salary
-   TA = 12% of basic salary
-   DA = 8% of basic salary
-   PF = 6% of basic salary
-   ESI = 4% of basic salary

HRA, TA and DA are added to the basic salary, while PF and ESI are
deducted.

## Formula

``` text
Total Salary = Basic + HRA + TA + DA - PF - ESI
```

## Python Program

``` python
# Finding total salary for the given basic salary
# 13% HRA, 12% TA, 8% DA, 6% PF, 4% ESI

basic = int(input("Enter basic salary : "))

HRA = 0.13 * basic
TA = 0.12 * basic
DA = 0.08 * basic
PF = 0.06 * basic
ESI = 0.04 * basic

total = basic + HRA + TA + DA - PF - ESI

print(f"Total salary : {total}")
```

Example:

``` text
Enter basic salary : 23000
Total salary : 28290.0
```

## Step-by-step calculation

For a basic salary of `23000`:

``` text
HRA = 13% of 23000 = 2990
TA  = 12% of 23000 = 2760
DA  =  8% of 23000 = 1840
PF  =  6% of 23000 = 1380
ESI =  4% of 23000 = 920
```

Therefore:

``` text
Total = 23000 + 2990 + 2760 + 1840 - 1380 - 920

Total = 28290
```

The program displays `28290.0` because percentage calculations such as:

``` python
0.13 * basic
```

produce floating-point values.

# 2. Relational Operators

A **relational operator**, also commonly called a **comparison
operator**, compares two values.

The result of a comparison is a Boolean value:

``` python
True
```

or:

``` python
False
```

For example:

``` python
print(5 > 3)
```

Output:

``` text
True
```

while:

``` python
print(5 == 3)
```

Output:

``` text
False
```

------------------------------------------------------------------------

## 2.1 Relational Operator Reference

  Operator   Meaning                    Example    Result
  ---------- -------------------------- ---------- ---------
  `>`        Greater than               `5 > 3`    `True`
  `<`        Less than                  `5 < 3`    `False`
  `>=`       Greater than or equal to   `5 >= 5`   `True`
  `<=`       Less than or equal to      `5 <= 3`   `False`
  `==`       Equal to                   `5 == 5`   `True`
  `!=`       Not equal to               `5 != 3`   `True`

# 4. Assignment `=` vs Equality `==`

This distinction is extremely important.

## Assignment

``` python
age = 18
```

means:

> Store the value `18` in the variable `age`.

## Equality comparison

``` python
age == 18
```

means:

> Is the value stored in `age` equal to `18`?

The result is `True` or `False`.

For example:

``` python
age = 18

print(age == 18)
```

Output:

``` text
True
```

# 6. The `if` Statement

An `if` statement executes a block of code **only when its condition
evaluates to `True`**.

Basic syntax:

``` python
if condition:
    statement_1
    statement_2
```

Conceptually:

``` text
START
  |
  v
Check condition
  |
  +---- True ----> Execute code
  |                    |
  +---- False ----------+
                       |
                       v
                      END
```

If the condition is false, Python skips the indented block.

------------------------------------------------------------------------

# 7. Indentation in Python

Python uses **indentation** to define blocks of code.

Correct:

``` python
age = 20

if age >= 18:
    print("Can vote")
```

The `print()` statement belongs to the `if` because it is indented.

Incorrect:

``` python
age = 20

if age >= 18:
print("Can vote")
```

This causes an `IndentationError`.

A standard Python convention is to use **4 spaces** for each indentation
level.

# 8. Example --- Discount Without a Condition

Suppose a shop gives a 20% discount.

The following program always applies the discount:

``` python
# Give 20% discount on bill

bill = int(input("Enter Bill : "))

discount = 0.20 * bill
bill = bill - discount

print(f"Pay : {bill}")
```

For:

``` text
Enter Bill : 8000
```

the calculation is:

``` text
20% of 8000 = 1600

8000 - 1600 = 6400
```

Output:

``` text
Pay : 6400.0
```

However, this program has a business-rule problem.

It applies the discount to **every bill**, even when the bill is small.

Suppose the actual requirement is:

> Give a 20% discount only when the bill is at least 5000.

Now we need a condition.

------------------------------------------------------------------------

# 9. Example --- Conditional Discount

Requirement:

> Apply a 20% discount only when the bill is `5000` or more.

``` python
# Give 20% discount on minimum bill 5000

bill = int(input("Enter Bill : "))

if bill >= 5000:
    discount = 0.20 * bill
    bill = bill - discount

print(f"Pay : {bill}")
```

## Example 1

Input:

``` text
3000
```

Condition:

``` python
3000 >= 5000
```

Result:

``` text
False
```

The discount block is skipped.

Output:

``` text
Pay : 3000
```

## Example 2

Input:

``` text
8000
```

Condition:

``` python
8000 >= 5000
```

Result:

``` text
True
```

Discount:

``` text
20% of 8000 = 1600
```

Final bill:

``` text
8000 - 1600 = 6400
```

Output:

``` text
Pay : 6400.0
```

This demonstrates why conditional statements are important: the same
program can behave differently depending on the input.

# 10. The `if-else` Statement

An `if-else` structure represents an **either/or decision**.

Basic syntax:

``` python
if condition:
    # Runs when condition is True
    statement
else:
    # Runs when condition is False
    statement
```

Exactly one of the two branches executes.

Conceptually:

``` text
              condition
             /         \
          True         False
           |             |
       if block       else block
           \             /
                END
```

# 12. Example --- Even or Odd

Requirement:

> Read a number and determine whether it is even.

``` python
# Check whether the number is even or not

n = int(input("Enter number : "))

if n % 2 == 0:
    print(f"{n} is Even")
else:
    print(f"{n} is not Even")
```

For:

``` text
n = 8
```

Python evaluates:

``` python
8 % 2 == 0
```

which is:

``` python
0 == 0
```

and therefore `True`.

Output:

``` text
8 is Even
```

For:

``` text
n = 7
```

Python evaluates:

``` python
7 % 2 == 0
```

which becomes:

``` python
1 == 0
```

and therefore `False`.

Output:

``` text
7 is not Even
```

A more conventional wording would be:

``` python
if n % 2 == 0:
    print(f"{n} is Even")
else:
    print(f"{n} is Odd")
```

# 13. The `if-elif-else` Statement

`if-else` is useful for two alternatives.

When there are **more than two possible situations**, Python provides
`elif`, meaning "else if".

Syntax:

``` python
if condition_1:
    statement
elif condition_2:
    statement
elif condition_3:
    statement
else:
    statement
```

Python checks the conditions from top to bottom.

As soon as one condition is `True`, its block executes and the remaining
branches are skipped.

------------------------------------------------------------------------

``` text
3 sides -> Triangle
4 sides -> Rectangle
5 sides -> Pentagon
```

``` python
sides = int(input("Enter num of sides : "))
```

``` text
Triangle
```

``` text
Enter num of sides : 5
Pentagon
```

If the input is:




# 15. Nested `if`

A **nested `if`** means placing one conditional statement inside another
conditional block.

Example structure:

``` python
if condition_1:
    if condition_2:
        statement
```

This is useful when the second condition should only be tested after the
first condition succeeds.

------------------------------------------------------------------------

# 16. Example --- Check Positive Number Before Even/Odd

Requirement:

1.  Read a number.
2.  Only perform the even/odd test when the number is positive.
3.  Otherwise display an error.

Lecture version:

``` python
# Nested if: writing an if block inside another if block
# Check whether the number is even or not (check only positive numbers)

n = int(input("Enter num : "))

if n > 0:
    if n % 2 == 0:
        print("Even num")
    else:
        print("Not Even num")
else:
    print("Error : Negative Num")
```

## How the nested decision works

The first condition is:

``` python
n > 0
```

If that condition is false, Python does not even perform the inner
even/odd test.

If it is true, Python reaches:

``` python
n % 2 == 0
```

The logic can be visualized as:

``` text
                    n > 0 ?
                   /       \
                True       False
                 |            |
                 v            v
             n % 2 == 0?   Error
              /      \
           True      False
            |          |
          Even       Not Even
```

------------------------------------------------------------------------

## Example: `n = 4`

First condition:

``` python
4 > 0
```

Result:

``` text
True
```

Then:

``` python
4 % 2 == 0
```

Result:

``` text
True
```

Output:

``` text
Even num
```

------------------------------------------------------------------------

## Example: `n = 3`

First condition:

``` python
3 > 0
```

is `True`.

Then:

``` python
3 % 2 == 0
```

is `False`.

Output:

``` text
Not Even num
```

------------------------------------------------------------------------

## Example: `n = -3`

First condition:

``` python
-3 > 0
```

is `False`.

Python goes directly to:

``` python
else:
    print("Error : Negative Num")
```

Output:

``` text
Error : Negative Num
```

# 17. Alternative Nested `if` Structure

The lecture also shows the validation in the opposite order:

``` python
n = int(input("Enter num : "))

if n < 0:
    print("Error : Negative Num")
else:
    if n % 2 == 0:
        print("Even num")
    else:
        print("Not Even num")
```

This says:

``` text
Is the number negative?

YES -> show error

NO  -> determine whether it is even
```

For many readers, this version can make the validation rule particularly
clear because invalid input is handled first.

# 18. Important Edge Case: Zero

The lecture requirement says to check only positive numbers.

The first version uses:

``` python
if n > 0:
```

Therefore `0` goes to the `else` branch.

However:

``` text
0 is neither positive nor negative.
```

Mathematically, `0` **is even**, because:

``` python
0 % 2 == 0
```

is `True`.

If the actual requirement is specifically:

> Negative numbers are invalid, but zero is allowed.

then use:

``` python
n = int(input("Enter num : "))

if n < 0:
    print("Error : Negative Num")
else:
    if n % 2 == 0:
        print("Even num")
    else:
        print("Odd num")
```

This is an example of why understanding the exact business requirement
matters when designing conditions.

# 19. Logical Operators

Relational expressions create conditions such as:

``` python
age >= 18
```

Sometimes one condition is not enough.

For example:

``` text
Age must be at least 18
AND
the person must have an ID
```

Python provides logical operators for combining or modifying Boolean
conditions.

The three operators introduced in the lecture are:

``` python
and
or
not
```

------------------------------------------------------------------------

# 20. Logical `and`

`and` requires **all combined conditions to be true**.

Example:

``` python
age = 25
has_id = True

print(age >= 18 and has_id)
```

Output:

``` text
True
```

But:

``` python
age = 25
has_id = False

print(age >= 18 and has_id)
```

Output:

``` text
False
```

## Truth table

  A         B         A `and` B
  --------- --------- -----------
  `True`    `True`    `True`
  `True`    `False`   `False`
  `False`   `True`    `False`
  `False`   `False`   `False`

Remember:

> With `and`, every required condition must be true.

------------------------------------------------------------------------

# 21. Logical `or`

`or` requires **at least one condition to be true**.

Example:

``` python
is_admin = False
is_manager = True

print(is_admin or is_manager)
```

Output:

``` text
True
```

because one condition is true.

## Truth table

  A         B         A `or` B
  --------- --------- ----------
  `True`    `True`    `True`
  `True`    `False`   `True`
  `False`   `True`    `True`
  `False`   `False`   `False`

Remember:

> With `or`, at least one condition must be true.

------------------------------------------------------------------------

# 22. Logical `not`

`not` reverses the truth value of a condition.

``` python
print(not True)
```

Output:

``` text
False
```

and:

``` python
print(not False)
```

Output:

``` text
True
```

Example:

``` python
logged_in = False

if not logged_in:
    print("Please log in")
```

Output:

``` text
Please log in
```

------------------------------------------------------------------------

# 23. Combining Relational and Logical Operators

Relational and logical operators are frequently used together.

Example:

``` python
age = 25
has_id = True

if age >= 18 and has_id:
    print("Eligible")
else:
    print("Not eligible")
```

Here:

``` python
age >= 18
```

is a relational expression, while:

``` python
and
```

combines it with another condition.

Another example:

``` python
day = "Saturday"

if day == "Saturday" or day == "Sunday":
    print("Weekend")
```

# 25. Common Beginner Mistakes

## Mistake 1 --- Using `=` instead of `==`

Incorrect:

``` python
if age = 18:
    print("Age is 18")
```

Correct:

``` python
if age == 18:
    print("Age is 18")
```

Remember:

``` text
=   assignment
==  comparison
```

------------------------------------------------------------------------

## Mistake 2 --- Forgetting the colon

Incorrect:

``` python
if age >= 18
    print("Can vote")
```

Correct:

``` python
if age >= 18:
    print("Can vote")
```

The colon `:` is required.

------------------------------------------------------------------------

## Mistake 3 --- Incorrect indentation

Incorrect:

``` python
if age >= 18:
print("Can vote")
```

Correct:

``` python
if age >= 18:
    print("Can vote")
```

------------------------------------------------------------------------

## Mistake 4 --- Incorrect modulo comparison

To check whether a number is even:

``` python
n % 2 == 0
```

not:

``` python
n / 2 == 0
```

Modulo checks the remainder.

------------------------------------------------------------------------

## Mistake 5 --- Confusing `elif` with multiple independent `if` statements

An `if-elif-else` chain selects the first matching branch.

``` python
if condition_1:
    ...
elif condition_2:
    ...
else:
    ...
```

Once one branch executes, the remaining branches in that chain are
skipped.

# 29. Key Takeaways

-   Percentage calculations can be implemented directly with arithmetic
    expressions.
-   Relational operators compare values and produce `True` or `False`.
-   `=` assigns a value; `==` compares values.
-   `%` is especially useful for divisibility and even/odd checks.
-   `if` executes code only when a condition is true.
-   `else` handles the alternative path.
-   `elif` allows more than two possible branches.
-   Nested `if` statements allow one decision to depend on another.
-   Indentation is part of Python syntax, not merely formatting.
-   `and` requires all combined conditions to be true.
-   `or` requires at least one combined condition to be true.
-   `not` reverses a Boolean condition.

These concepts form the foundation for decision-making and business-rule
implementation in Python.
